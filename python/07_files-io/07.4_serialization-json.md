# 07.4 Serialization — JSON, Pickle, CSV and Beyond

> Files store bytes. Python objects live in memory. *Serialization* bridges the
> two: converting objects → bytes (or text) for storage or transmission, and
> back. Get it wrong and you corrupt data, leak security holes, or lock yourself
> into an unportable format.

## What Serialization Means

```
Python object  ──dump/encode──▶  bytes / str  ──write──▶  file / socket
                ◀──load/decode──               ◀──read──
```

- **Serialization** (dumping, encoding, marshalling): object → serial form.
- **Deserialization** (loading, decoding, unmarshalling): serial form → object.

Python offers many serializers. Each makes different trade-offs among
human-readability, speed, portability, type fidelity, and safety.

| Format | Human-readable | Stdlib | Types preserved | Cross-language | Safe to load untrusted? |
|--------|----------------|--------|-----------------|----------------|-------------------------|
| **JSON** | Yes | `json` | Limited (see §1) | Yes | Yes |
| **Pickle** | No (binary) | `pickle` | Almost all Python types | No (Python only) | **No — arbitrary code exec** |
| **CSV** | Yes | `csv` | Strings only | Yes | Yes (but beware formula injection in Excel) |
| **TOML** | Yes | `tomllib` (3.11+) / `tomli` | Good for config | Yes | Yes |
| **INI** | Yes | `configparser` | Strings only | Yes | Yes |
| **YAML** | Yes | 3rd-party (`PyYAML`, `ruamel.yaml`) | Rich | Yes | Depends (`safe_load` vs `load`) |
| **MessagePack / CBOR / Protobuf** | No | 3rd-party | Rich | Yes | Yes (with care) |

This lesson covers JSON deeply, pickle's dangers, CSV correctly, `configparser`
briefly, and how to choose.

## 1. JSON — The Default Interchange Format

JSON (RFC 8259) has six value types:

| JSON type | Python counterpart (load) | Python → JSON (dump) |
|-----------|---------------------------|----------------------|
| object `{"k": v}` | `dict` (keys always `str`) | `dict` with `str` keys |
| array `[1,2]` | `list` | `list`, `tuple` → array |
| string `"hi"` | `str` | `str` |
| number `42`, `3.14` | `int`, `float` | `int`, `float`, `Decimal` (if configured) |
| `true` / `false` | `True` / `False` | `True` / `False` |
| `null` | `None` | `None` |
| *(no date, bytes, set, …)* | — | `TypeError` unless custom-handled |

### 1.1 The Four Functions

```python
import json

# 1. dumps — object → str
s = json.dumps({"name": "Ada", "age": 36})
print(s)  # '{"name": "Ada", "age": 36}'
print(type(s))  # str

# 2. loads — str/bytes/bytearray → object
obj = json.loads(s)
print(obj)  # {'name': 'Ada', 'age': 36}

# 3. dump — object → file (text mode)
with open("data.json", "w", encoding="utf-8") as f:
    json.dump({"name": "Ada", "age": 36}, f)

# 4. load — file (text mode) → object
with open("data.json", encoding="utf-8") as f:
    obj2 = json.load(f)
print(obj2)
```

> `dump`/`load` work with *text* files. For binary files, wrap or use `dumps` +
> `write_bytes` with explicit encoding.

### 1.2 Common Parameters — `dumps` / `dump`

```python
import json
from decimal import Decimal
from datetime import datetime

data = {"b": 2, "a": 1, "msg": "héllo 🌍"}

# indent — pretty-print
print(json.dumps(data, indent=2))
# {
#   "b": 2,
#   "a": 1,
#   "msg": "héllo 🌍"
# }

# sort_keys — deterministic key order (useful for diffing / hashing)
print(json.dumps(data, sort_keys=True))
# {"a": 1, "b": 2, "msg": "héllo 🌍"}

# ensure_ascii — escape non-ASCII as \uXXXX
print(json.dumps(data, ensure_ascii=True))   # "h\u00e9llo \ud83c\udf0d"
print(json.dumps(data, ensure_ascii=False))  # "héllo 🌍" — readable, needs utf-8 file

# separators — compact output (no spaces)
print(json.dumps(data, separators=(",", ":")))  # '{"b":2,"a":1,"msg":"héllo 🌍"}'

# allow_nan — False rejects NaN/Infinity (which are not valid JSON per spec)
try:
    json.dumps(float("nan"), allow_nan=False)
except ValueError as exc:
    print(f"NaN rejected: {exc}")

# default — called for non-serializable objects (see §2)
# cls — custom JSONEncoder subclass (see §2)

# Combining for production: human-readable, stable, utf-8
with open("pretty.json", "w", encoding="utf-8") as f:
    json.dump(data, f, indent=2, sort_keys=True, ensure_ascii=False)
    f.write("\n")  # trailing newline — POSIX convention, nicer with cat / git
```

> **Recommendation:** For config / storage, use `indent=2, sort_keys=True,
> ensure_ascii=False` and write with `encoding="utf-8"`. For wire / compact,
> use `separators=(",", ":")` without indent.

### 1.3 Correct File I/O With JSON

```python
import json
from pathlib import Path

data = {"users": [{"id": 1, "name": "Ada"}, {"id": 2, "name": "Bob"}]}

# Write — text mode, utf-8, newline="\n" for portability
with open("users.json", "w", encoding="utf-8", newline="\n") as f:
    json.dump(data, f, indent=2, ensure_ascii=False)
    f.write("\n")

# Read — text mode, utf-8
with open("users.json", encoding="utf-8") as f:
    loaded = json.load(f)
print(loaded)

# Path convenience (small files)
Path("users2.json").write_text(
    json.dumps(data, indent=2, ensure_ascii=False) + "\n", encoding="utf-8"
)
loaded2 = json.loads(Path("users2.json").read_text(encoding="utf-8"))
print(loaded2 == data)  # True
```

## 2. JSON Pitfalls and How to Handle Them

### 2.1 Types JSON Cannot Represent

```python
import json
from datetime import datetime, date
from decimal import Decimal

# These all raise TypeError by default:
cases = [
    datetime.now(),           # no date type in JSON
    Decimal("3.14"),          # technically a number, but json treats Decimal specially
    {1, 2, 3},                # set
    b"bytes",                 # bytes
    complex(1, 2),            # complex
    float("nan"),             # allowed only if allow_nan=True (default)
]

for val in cases:
    try:
        print(f"{type(val).__name__}: {json.dumps(val)}")
    except TypeError as exc:
        print(f"{type(val).__name__} failed: {exc}")
```

Output:

```
datetime failed: Object of type datetime is not JSON serializable
Decimal: 3.14          — actually succeeds! (see below)
set failed: Object of type set is not JSON serializable
bytes failed: Object of type bytes is not JSON serializable
complex failed: Object of type complex is not JSON serializable
```

> **Surprise — `Decimal`:** `json` *does* handle `Decimal` if you pass it, but
> it serialises as a JSON number (`3.14`), and `json.load` will return a `float`
> by default, **losing precision**. Use `parse_float=Decimal` on load to preserve
> it (see §2.4).

### 2.2 Silent Data Loss — Tuples, Dict Keys, Infinity

```python
import json

# Tuple → array → list (round-trip changes type!)
print(json.dumps((1, 2)))          # '[1, 2]'
print(type(json.loads('[1, 2]')))  # <class 'list'> — not tuple!

# Dict with non-string keys → keys become strings!
print(json.dumps({1: "a", 2: "b"}))  # '{"1": "a", "2": "b"}'
print(json.loads('{"1": "a"}'))      # {'1': 'a'} — keys are now str!

# Float special values — valid in Python, technically invalid JSON (but allowed by default)
print(json.dumps(float("nan")))   # 'NaN'
print(json.dumps(float("inf")))   # 'Infinity'
# Many strict JSON parsers (Go, JSON spec) reject these!
# Prefer allow_nan=False and handle explicitly.
```

| Pitfall | Effect | Mitigation |
|---------|--------|------------|
| `tuple` → `list` | Type change on round-trip | Convert back manually, or use custom encoding |
| `dict` int keys → `str` keys | Key type loss | Avoid non-string keys, or encode keys specially |
| `Decimal` → `float` | Precision loss | `parse_float=Decimal` on load |
| `NaN`/`Infinity` | Non-standard JSON | `allow_nan=False` + custom handling |
| `bytes` | `TypeError` | Base64-encode or `decode("utf-8")` first |
| `set` | `TypeError` | Convert to `sorted(list(s))` for determinism |

### 2.3 Custom Encoding — `default` and `JSONEncoder`

Two equivalent approaches for serialising non-standard types.

#### Approach A: `default` Callback (Simplest)

```python
import json
from datetime import datetime, date
from decimal import Decimal
import base64

def json_default(obj):
    """Called for objects json doesn't know. Return a JSON-serializable form."""
    if isinstance(obj, (datetime, date)):
        return obj.isoformat()          # "2026-09-25T14:30:00"
    if isinstance(obj, Decimal):
        return str(obj)                 # preserve precision as string
    if isinstance(obj, set):
        return sorted(obj)              # deterministic
    if isinstance(obj, bytes):
        return {"__bytes__": base64.b64encode(obj).decode("ascii")}
    raise TypeError(f"Object of type {type(obj).__name__} is not JSON serializable")

data = {
    "when": datetime(2026, 9, 25, 14, 30, 0),
    "price": Decimal("19.99"),
    "tags": {"b", "a"},
    "payload": b"hello",
}

s = json.dumps(data, default=json_default, indent=2, ensure_ascii=False)
print(s)

# To decode, use object_hook (see below) to reverse the transformation
```

**Explanation:** `default` is called only when the default encoder fails. It must
return a JSON-serializable object (e.g., `str`, `list`, `dict`) or raise
`TypeError`.

#### Approach B: Subclass `JSONEncoder` (More Control)

```python
import json
from datetime import datetime, date

class DateTimeEncoder(json.JSONEncoder):
    def default(self, obj):
        if isinstance(obj, (datetime, date)):
            return obj.isoformat()
        return super().default(obj)  # raises TypeError for unknown types

s = json.dumps({"when": datetime.now()}, cls=DateTimeEncoder)
print(s)

# Also controls other aspects:
class PrettyEncoder(json.JSONEncoder):
    def encode(self, obj):
        # Custom top-level encoding if needed
        return super().encode(obj)

    def iterencode(self, obj, _one_shot=False):
        return super().iterencode(obj, _one_shot)
```

> Prefer `default` for one-off cases; prefer a subclass when you need to reuse
> the encoder or override `encode`/`iterencode` for streaming.

### 2.4 Custom Decoding — `object_hook`, `parse_float`, `parse_int`

```python
import json
from datetime import datetime
from decimal import Decimal
import base64

# Example JSON produced by json_default above
s = '''
{
  "when": "2026-09-25T14:30:00",
  "price": "19.99",
  "tags": ["a", "b"],
  "payload": {"__bytes__": "aGVsbG8="}
}
'''

def json_object_hook(d: dict):
    # Called for EVERY JSON object (dict). Return transformed dict.
    # Detect our bytes marker:
    if "__bytes__" in d and len(d) == 1:
        return base64.b64decode(d["__bytes__"])
    # Try to parse ISO datetime strings for known keys:
    # (In real code, you might try to parse all string values that look like datetimes)
    if "when" in d and isinstance(d["when"], str):
        try:
            d["when"] = datetime.fromisoformat(d["when"])
        except ValueError:
            pass
    # Decimal from string
    if "price" in d and isinstance(d["price"], str):
        try:
            d["price"] = Decimal(d["price"])
        except Exception:
            pass
    return d

obj = json.loads(s, object_hook=json_object_hook)
print(obj)
print(type(obj["when"]), type(obj["price"]), type(obj["payload"]))
# <class 'datetime.datetime'> <class 'decimal.Decimal'> <class 'bytes'>

# Preserve Decimal precision for numbers that ARE JSON numbers:
num_json = '{"price": 19.99}'
print(json.loads(num_json))  # {'price': 19.99} — float!
print(json.loads(num_json, parse_float=Decimal))  # {'price': Decimal('19.99')}

# parse_int — e.g., preserve large integers as Decimal or int subclasses
print(json.loads('{"big": 12345678901234567890}', parse_int=Decimal))

# object_pairs_hook — preserves order / handles duplicate keys
from collections import OrderedDict
print(json.loads('{"b": 2, "a": 1}', object_pairs_hook=OrderedDict))
```

> **When to use what:**
> - `object_hook` — transform dicts after parsing (most common for custom types).
> - `parse_float` / `parse_int` — control number parsing (e.g., `Decimal`).
> - `object_pairs_hook` — when key order or duplicate keys matter (replaces
>   `object_hook`; receives `list[tuple[str, Any]]`).

### 2.5 Full Round-Trip Example — Dataclass With JSON

```python
import json
from dataclasses import dataclass, asdict
from datetime import datetime
from pathlib import Path

@dataclass
class Event:
    title: str
    when: datetime
    attendees: list[str]

def event_default(obj):
    if isinstance(obj, datetime):
        return {"__datetime__": obj.isoformat()}
    raise TypeError(f"not serializable: {obj!r}")

def event_hook(d: dict):
    if "__datetime__" in d:
        return datetime.fromisoformat(d["__datetime__"])
    return d

events = [
    Event("Sprint Review", datetime(2026, 9, 25, 10, 0), ["Ada", "Bob"]),
    Event("Retro", datetime(2026, 9, 26, 15, 0), ["Ada", "Cara"]),
]

# Dataclass → dict → JSON
payload = [asdict(e) for e in events]
Path("events.json").write_text(
    json.dumps(payload, default=event_default, indent=2, ensure_ascii=False) + "\n",
    encoding="utf-8",
)

# JSON → dict → dataclass
raw = json.loads(Path("events.json").read_text(encoding="utf-8"), object_hook=event_hook)
restored = [Event(**d) for d in raw]
print(restored)
print(restored[0].when, type(restored[0].when))
```

For production, consider libraries like `pydantic`, `cattrs`, or `dataclasses-json`
that automate this mapping with validation.

## 3. Pickle — Powerful, Python-Only, and Dangerous

`pickle` serialises *almost any* Python object — including custom classes,
functions, and circular references — to a binary format.

```python
import pickle
from pathlib import Path

data = {"a": [1, 2, {"x": True}], "b": {1, 2, 3}}

# dumps / loads — bytes
blob = pickle.dumps(data, protocol=pickle.HIGHEST_PROTOCOL)
print(blob[:20], len(blob))
restored = pickle.loads(blob)
print(restored == data)  # True — sets, tuples, etc. preserved!

# dump / load — binary files
with open("data.pkl", "wb") as f:
    pickle.dump(data, f, protocol=pickle.HIGHEST_PROTOCOL)

with open("data.pkl", "rb") as f:
    print(pickle.load(f))
```

### 3.1 Protocol Versions

| Protocol | Python | Notes |
|----------|--------|-------|
| 0 | 1.x | ASCII, very old |
| 1 | 2.x | Binary, old |
| 2 | 2.3 | New-style classes |
| 3 | 3.0 | `bytes` support |
| 4 | 3.4 | Large objects, `__qualname__` |
| 5 | 3.8 | Out-of-band buffers (`PickleBuffer`) |
| `HIGHEST_PROTOCOL` | current | Best for new files you control |

> Always use `HIGHEST_PROTOCOL` for files you write and read with the same
> Python version. For long-term storage, JSON is better — pickle protocols
> evolve and are not cross-language.

### 3.2 Why Pickle Is Dangerous — Never Load Untrusted Data

Unpickling executes arbitrary Python code. This is by design (it must
reconstruct objects), but it means a malicious pickle can own your machine.

```python
import pickle
import os

# Malicious payload — when unpickled, runs os.system
class Evil:
    def __reduce__(self):
        # __reduce__ tells pickle how to reconstruct the object:
        # it returns (callable, args) and pickle calls callable(*args)
        return (os.system, ("echo pwned",))

blob = pickle.dumps(Evil())
print("blob created, now unpickling...")

# This executes `os.system("echo pwned")`!
pickle.loads(blob)  # prints "pwned" via shell

# Same danger with pickle.load on a file:
# with open("untrusted.pkl", "rb") as f:
#     pickle.load(f)  # arbitrary code execution if file is attacker-controlled
```

**Rules:**

- **Never** `pickle.load` / `pickle.loads` on data from untrusted sources
  (uploads, network, cookies, user-supplied files).
- **Never** send pickles to clients that will unpickle them if the channel is
  not fully trusted.
- Prefer JSON (or MessagePack, CBOR, protobuf) for untrusted data — they cannot
  execute code.
- If you must use pickle, sign it (HMAC) or encrypt it, and verify before
  unpickling — but even then, JSON is simpler and safer.

### 3.3 Safer Alternatives to Pickle

| Need | Alternative |
|------|-------------|
| Human-readable config | JSON, TOML, YAML (`safe_load`) |
| Binary, cross-language | MessagePack, CBOR, protobuf, flatbuffers |
| Python objects, safe | `json` + custom `default`/`object_hook`, or `pydantic` |
| Caching Python objects you control | `pickle` is okay **if** you control both ends and verify integrity |
| Deep copy of objects | `copy.deepcopy` (no serialisation needed) |

```python
# Example: signed pickle (illustrative — use cryptography library in production)
import hmac, hashlib, pickle

SECRET = b"change-me-to-a-real-secret"

def dumps_signed(obj) -> bytes:
    blob = pickle.dumps(obj, protocol=pickle.HIGHEST_PROTOCOL)
    sig = hmac.new(SECRET, blob, hashlib.sha256).hexdigest()
    return sig.encode() + b":" + blob

def loads_signed(data: bytes):
    sig, blob = data.split(b":", 1)
    expected = hmac.new(SECRET, blob, hashlib.sha256).hexdigest().encode()
    if not hmac.compare_digest(sig, expected):
        raise ValueError("invalid signature — possible tampering")
    return pickle.loads(blob)  # safe only if signature is valid AND secret is safe
```

## 4. CSV — Tabular Text Done Correctly

CSV looks simple (`a,b,c`) until you hit fields containing commas, quotes, or
newlines. The `csv` module handles RFC 4180 correctly.

### 4.1 The One Rule — `newline=""`

```python
import csv

# ALWAYS use newline="" with csv — otherwise Windows translates \r\n and you get blank lines
with open("data.csv", "w", encoding="utf-8", newline="") as f:
    writer = csv.writer(f)
    writer.writerow(["name", "age", "note"])
    writer.writerow(["Ada", 36, 'loves "quotes" and, commas'])

with open("data.csv", encoding="utf-8", newline="") as f:
    reader = csv.reader(f)
    for row in reader:
        print(row)
# ['name', 'age', 'note']
# ['Ada', '36', 'loves "quotes" and, commas']
```

> Forgetting `newline=""` is the most common CSV bug. On Windows, the default
> newline translation turns `writer`'s `\r\n` into `\r\r\n`, producing blank
> lines. On read, it mangles embedded newlines.

### 4.2 `csv.writer` / `csv.reader` — Basics and Quoting

```python
import csv

rows = [
    ["id", "name", "bio"],
    [1, "Ada", "Line 1\nLine 2"],       # embedded newline
    [2, "Bob", 'Has, comma and "quote"'],
]

# Writing — quoting is automatic
with open("people.csv", "w", encoding="utf-8", newline="") as f:
    w = csv.writer(f, quoting=csv.QUOTE_MINIMAL, lineterminator="\n")
    w.writerows(rows)

# Inspect the raw file — note quoted fields
from pathlib import Path
print(Path("people.csv").read_text(encoding="utf-8"))

# Reading — handles quotes and embedded newlines automatically
with open("people.csv", encoding="utf-8", newline="") as f:
    r = csv.reader(f)
    header = next(r)
    print("header:", header)
    for row in r:
        print(row)
        # row is list[str] — csv never converts types; "1" stays "1"
```

| Quoting | Behaviour |
|---------|-----------|
| `QUOTE_MINIMAL` (default) | Quote only fields containing delimiter, quotechar, or lineterminator |
| `QUOTE_ALL` | Quote every field |
| `QUOTE_NONNUMERIC` | Quote non-numeric fields; reader converts unquoted → `float` |
| `QUOTE_NONE` | Never quote (requires `escapechar`) |

```python
import csv, io

buf = io.StringIO()
w = csv.writer(buf, quoting=csv.QUOTE_ALL, lineterminator="\n")
w.writerow(["a", "b"])
print(repr(buf.getvalue()))  # '"a","b"\n'

buf = io.StringIO()
w = csv.writer(buf, quoting=csv.QUOTE_NONNUMERIC, lineterminator="\n")
w.writerow(["a", 1, 3.14])
print(repr(buf.getvalue()))  # '"a",1,3.14\n'
# And on read, 1 and 3.14 become float:
buf.seek(0)
print(next(csv.reader(buf, quoting=csv.QUOTE_NONNUMERIC)))  # ['a', 1.0, 3.14]
```

### 4.3 `DictReader` / `DictWriter` — Column Names

```python
import csv

# DictWriter — map dicts to CSV columns
with open("users.csv", "w", encoding="utf-8", newline="") as f:
    fieldnames = ["id", "name", "email"]
    w = csv.DictWriter(f, fieldnames=fieldnames, lineterminator="\n")
    w.writeheader()
    w.writerow({"id": 1, "name": "Ada", "email": "ada@example.com"})
    w.writerow({"id": 2, "name": "Bob"})  # missing email → empty field

# DictReader — each row is a dict
with open("users.csv", encoding="utf-8", newline="") as f:
    r = csv.DictReader(f)
    print(r.fieldnames)  # ['id', 'name', 'email']
    for row in r:
        print(row)  # {'id': '1', 'name': 'Ada', 'email': 'ada@example.com'}
        print(type(row["id"]))  # str — even numbers are strings
```

> `DictReader`/`DictWriter` are the most readable for CSV with headers. Remember
> that all values are `str` (or `None` for missing with `restval`).

### 4.4 Dialects, Delimiters, and `Sniffer`

```python
import csv

# Custom delimiter — e.g., TSV
with open("data.tsv", "w", encoding="utf-8", newline="") as f:
    w = csv.writer(f, delimiter="\t", lineterminator="\n")
    w.writerow(["a", "b\twith tab", "c"])

with open("data.tsv", encoding="utf-8", newline="") as f:
    r = csv.reader(f, delimiter="\t")
    print(next(r))

# Dialect — named style
csv.register_dialect("excel-tab", delimiter="\t", quoting=csv.QUOTE_MINIMAL)
with open("data2.tsv", "w", encoding="utf-8", newline="") as f:
    w = csv.writer(f, dialect="excel-tab", lineterminator="\n")
    w.writerow(["x", "y"])

# Sniffer — guess dialect from a sample (useful for unknown inputs)
sample = 'a,b,c\n1,2,3\n'
dialect = csv.Sniffer().sniff(sample)
print(dialect.delimiter)  # ,
print(csv.Sniffer().has_header(sample))  # True
```

### 4.5 Pitfalls and Type Conversion

```python
import csv

# Pitfall 1: All fields are strings — convert manually
with open("users.csv", encoding="utf-8", newline="") as f:
    for row in csv.DictReader(f):
        row["id"] = int(row["id"])  # convert
        print(row, type(row["id"]))

# Pitfall 2: Embedded newlines require newline="" — otherwise they break
# Pitfall 3: Different encodings — Excel often expects cp1252 or utf-8-sig
with open("for_excel.csv", "w", encoding="utf-8-sig", newline="") as f:
    w = csv.writer(f, lineterminator="\n")
    w.writerow(["name", "value"])
    w.writerow(["café", 123])

# Pitfall 4: Large files — iterate, don't load all at once
def iter_csv(path: str):
    with open(path, encoding="utf-8", newline="") as f:
        yield from csv.DictReader(f)

for row in iter_csv("users.csv"):
    process(row) if False else print(row)

# Pitfall 5: Formula injection — if CSV is opened in Excel, cells starting with
# = + - @ may execute. Sanitize by prefixing with ' or space if needed:
def sanitize_for_excel(value: str) -> str:
    if value and value[0] in "=+-@":
        return "'" + value
    return value
```

## 5. `configparser` — INI-Style Configuration (Brief)

For simple `key = value` config with sections, `configparser` is the stdlib
choice (TOML is modern alternative).

```python
import configparser
from pathlib import Path

cfg = configparser.ConfigParser()
cfg["DEFAULT"] = {"debug": "false", "workers": "4"}
cfg["server"] = {"host": "127.0.0.1", "port": "8000"}
cfg["auth"] = {"secret": "s3cr3t"}

# Write
with open("app.ini", "w", encoding="utf-8") as f:
    cfg.write(f)

print(Path("app.ini").read_text(encoding="utf-8"))
# [DEFAULT]
# debug = false
# workers = 4
#
# [server]
# host = 127.0.0.1
# port = 8000
#
# [auth]
# secret = s3cr3t

# Read
cfg2 = configparser.ConfigParser()
cfg2.read("app.ini", encoding="utf-8")
print(cfg2["server"]["host"])          # 127.0.0.1
print(cfg2["server"].getint("port"))   # 8000 — typed getters
print(cfg2["server"].getboolean("debug"))  # False — falls back to DEFAULT
print(cfg2.getint("server", "workers"))   # 4 — from DEFAULT

# Interpolation — %(key)s in values
cfg3 = configparser.ConfigParser(interpolation=configparser.BasicInterpolation())
cfg3.read_string("[paths]\nroot = /app\ndata = %(root)s/data\n")
print(cfg3["paths"]["data"])  # /app/data
```

> `configparser` is case-insensitive for keys by default (`optionxform=str.lower`).
> For case-sensitive keys: `cfg = ConfigParser(); cfg.optionxform = str`.

## 6. Choosing a Format — Decision Guide

```python
# When to use what:

# JSON — API payloads, structured storage, cross-language, human-readable
import json
json.dumps({"key": "value"})

# TOML — modern config (pyproject.toml, Cargo-like). Python 3.11+ has tomllib:
try:
    import tomllib  # Python 3.11+
    with open("pyproject.toml", "rb") as f:
        data = tomllib.load(f)  # note: binary mode!
    print(data)
except ModuleNotFoundError:
    import tomli as tomllib  # backport

# YAML — complex config with nesting, but needs safe_load:
# import yaml
# yaml.safe_load(open("config.yaml", encoding="utf-8"))

# pickle — only for trusted, Python-internal, ephemeral data (caches, queues)
# csv — tabular data exchange, spreadsheets
# configparser — legacy INI config (prefer TOML for new projects)
# protobuf / msgpack — high-performance binary protocols
```

| Need | Recommended |
|------|-------------|
| API / web | JSON |
| Config (new) | TOML (`tomllib` / `tomli`) |
| Config (legacy) | `configparser` (INI) |
| Tabular / Excel | CSV (`csv` with `newline=""`) |
| High-throughput binary | MessagePack, CBOR, protobuf |
| Python-only ephemeral (cache) | `pickle` with HMAC + `HIGHEST_PROTOCOL` |
| Long-term storage | JSON or TOML — not pickle |

## 7. Realistic End-to-End Examples

### Example 1: JSON Lines (JSONL) — Streaming Structured Logs

JSONL = one JSON object per line. Ideal for logs and large datasets — streamable,
grep-able, appendable.

```python
import json
from pathlib import Path
from datetime import datetime, timezone

LOG = Path("events.jsonl")

def append_event(path: Path, event: dict) -> None:
    with open(path, "a", encoding="utf-8") as f:
        json.dump(event, f, ensure_ascii=False, default=str)
        f.write("\n")

def iter_events(path: Path):
    with open(path, encoding="utf-8") as f:
        for line in f:
            line = line.strip()
            if line:
                yield json.loads(line)

# Write
LOG.write_text("", encoding="utf-8")  # truncate
for i in range(3):
    append_event(LOG, {"id": i, "at": datetime.now(timezone.utc).isoformat(), "msg": f"event {i}"})

# Read — constant memory
for ev in iter_events(LOG):
    print(ev)
```

### Example 2: Robust JSON Config With Validation

```python
import json
from pathlib import Path

DEFAULT_CONFIG = {"host": "127.0.0.1", "port": 8000, "debug": False}

def load_config(path: Path) -> dict:
    try:
        data = json.loads(path.read_text(encoding="utf-8"))
    except FileNotFoundError:
        print(f"{path} not found — using defaults")
        return dict(DEFAULT_CONFIG)
    except json.JSONDecodeError as exc:
        raise ValueError(f"invalid JSON in {path}: {exc}") from exc

    # Validate — fail fast on wrong types
    if not isinstance(data.get("port", 8000), int):
        raise ValueError("port must be int")
    if not isinstance(data.get("host", ""), str):
        raise ValueError("host must be str")

    # Merge defaults
    cfg = {**DEFAULT_CONFIG, **data}
    return cfg

# Demo
Path("config.json").write_text(json.dumps({"port": 9000}, indent=2), encoding="utf-8")
print(load_config(Path("config.json")))
print(load_config(Path("missing.json")))
```

### Example 3: CSV → JSON Pipeline With Type Coercion

```python
import csv
import json
from pathlib import Path

# Assume input.csv: id,name,score
# 1,Ada,95.5
# 2,Bob,80.0

def csv_to_json(csv_path: Path, json_path: Path) -> None:
    with open(csv_path, encoding="utf-8", newline="") as fin:
        reader = csv.DictReader(fin)
        rows = []
        for row in reader:
            # Coerce types — csv gives everything as str
            rows.append({
                "id": int(row["id"]),
                "name": row["name"],
                "score": float(row["score"]),
            })

    with open(json_path, "w", encoding="utf-8", newline="\n") as fout:
        json.dump(rows, fout, indent=2, ensure_ascii=False)
        fout.write("\n")

# Create demo CSV
Path("input.csv").write_text("id,name,score\n1,Ada,95.5\n2,Bob,80.0\n", encoding="utf-8")
csv_to_json(Path("input.csv"), Path("output.json"))
print(Path("output.json").read_text(encoding="utf-8"))
```

### Example 4: Pickle Cache With Integrity Check (When You Control Both Ends)

```python
import pickle
import hashlib
import hmac
from pathlib import Path

SECRET = b"dev-only-secret-change-me"

def cache_set(path: Path, obj, secret: bytes = SECRET) -> None:
    blob = pickle.dumps(obj, protocol=pickle.HIGHEST_PROTOCOL)
    digest = hmac.new(secret, blob, hashlib.sha256).hexdigest()
    # Store digest + blob
    with open(path, "wb") as f:
        f.write(digest.encode() + b"\n")
        f.write(blob)

def cache_get(path: Path, secret: bytes = SECRET):
    with open(path, "rb") as f:
        digest = f.readline().strip()
        blob = f.read()
    expected = hmac.new(secret, blob, hashlib.sha256).hexdigest().encode()
    if not hmac.compare_digest(digest, expected):
        raise ValueError("cache tampered or secret changed")
    return pickle.loads(blob)

# Usage
cache_set(Path("cache.pkl"), {"expensive": [1, 2, 3]})
print(cache_get(Path("cache.pkl")))
```

## 8. Pitfalls and Edge Cases

| Pitfall | Symptom | Fix |
|---------|---------|-----|
| `json.dump` to binary file | `TypeError: write() argument must be str` | Use text mode `encoding="utf-8"` |
| Forgetting `ensure_ascii=False` | `\uXXXX` escapes instead of readable Unicode | Pass `ensure_ascii=False` + `encoding="utf-8"` |
| `tuple`/`set`/`bytes` in JSON | `TypeError` or silent type change | Custom `default` + `object_hook` |
| Large ints / `Decimal` precision loss | `19.99` → `19.9900000001` | `parse_float=Decimal`, encode `Decimal` as `str` |
| `NaN`/`Infinity` in JSON | Rejected by strict parsers | `allow_nan=False` |
| `pickle` on untrusted data | **Remote code execution** | Never unpickle untrusted data; use JSON |
| CSV `newline=""` omitted | Blank lines on Windows | Always `open(..., newline="")` for `csv` |
| CSV all-strings | `"1"` not `1` | Convert manually (`int()`, `float()`) |
| `configparser` key case | `Key` → `key` | `cfg.optionxform = str` for case-sensitive |
| `tomllib.load` needs binary | `TypeError` | `open("file.toml", "rb")` |
| JSON duplicate keys | Last wins silently | `object_pairs_hook` to detect |

## Summary

- **JSON** is the default for interchange: `dumps`/`loads` for strings,
  `dump`/`load` for text files. Use `indent`, `sort_keys`, `ensure_ascii=False`
  for readable output; `separators=(",", ":")` for compact.
- JSON supports only six types. Everything else (`datetime`, `Decimal`, `bytes`,
  `set`, `tuple`) needs explicit handling via `default` / `JSONEncoder` and
  `object_hook` / `parse_float`.
- **Silent pitfalls:** tuples become lists, int dict keys become strings,
  `Decimal` loses precision, `NaN` is non-standard. Handle each deliberately.
- **Pickle** preserves almost any Python object but is **unsafe on untrusted
  data** — unpickling executes arbitrary code. Use `HIGHEST_PROTOCOL` and HMAC
  if you must pickle; prefer JSON otherwise.
- **CSV** requires `newline=""`, handles quoting/embedded newlines automatically,
  yields `str` only — convert types manually. Use `DictReader`/`DictWriter` for
  headers.
- **configparser** handles INI with typed getters; for new config prefer TOML
  (`tomllib` reads in binary mode).
- Choose formats by trade-off: JSON for APIs, TOML for config, CSV for tabular,
  pickle only for trusted ephemeral caches, binary protocols (MessagePack/protobuf)
  for performance.
