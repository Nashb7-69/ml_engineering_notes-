# 07.3 pathlib — Object-Oriented Filesystem Paths

> String manipulation for paths (`os.path.join`, `+ "/" +`, `split("/")`) is
> error-prone, platform-dependent, and hard to read. `pathlib` replaces it with
> an object-oriented `Path` that knows it is a path.

## Why `pathlib` Exists

Before Python 3.4 (when `pathlib` was introduced), path handling looked like:

```python
import os
base = "/home/ada"
path = os.path.join(base, "projects", "app", "data.txt")
name = os.path.basename(path)
ext = os.path.splitext(path)[1]
parent = os.path.dirname(path)
exists = os.path.exists(path)
```

Every operation is a free function that takes a `str`. No type distinction between
"a path" and "any string". Easy to forget `os.path.join` and write
`base + "/" + name` — which breaks on Windows.

`pathlib` replaces this with:

```python
from pathlib import Path
base = Path("/home/ada")
path = base / "projects" / "app" / "data.txt"
name = path.name
ext = path.suffix
parent = path.parent
exists = path.exists()
```

Benefits:

- **Operator `/` for joining** — readable, portable, no string hacking.
- **Methods on the path itself** — discoverable via tab-completion.
- **Type safety** — `Path` is distinct from `str`; functions that expect a path
  can type-hint `Path` or `os.PathLike`.
- **Cross-platform semantics** — `PurePath` flavours handle POSIX vs Windows
  differences without touching the filesystem.
- **Modern stdlib integration** — `open(Path)`, `os.fspath(Path)`, and most
  stdlib functions accept `Path` via the `os.PathLike` protocol (PEP 519).

> **Should you still use `os.path`?** New code should prefer `pathlib`. `os.path`
> remains for legacy code, for `str`-only pipelines, and for a few operations
> without a `pathlib` equivalent (e.g., `os.path.expanduser` has `Path.expanduser`
> but `os.path.expandvars` has no `pathlib` counterpart — use `os.path.expandvars(os.fspath(p))`).

## 1. `Path` vs `PurePath`

| Class | Touches filesystem? | Knows OS flavour | Example |
|-------|---------------------|------------------|---------|
| `PurePosixPath` | No | POSIX (`/`) | `PurePosixPath("a/b")` |
| `PureWindowsPath` | No | Windows (`\`, `C:\`) | `PureWindowsPath(r"C:\a\b")` |
| `PurePath` | No | **Current OS** | Alias to one of the above |
| `PosixPath` | Yes | POSIX | `PosixPath("/tmp")` |
| `WindowsPath` | Yes | Windows | `WindowsPath(r"C:\tmp")` |
| `Path` | Yes | **Current OS** | Alias to `PosixPath` or `WindowsPath` |

```python
from pathlib import Path, PurePosixPath, PureWindowsPath

# Pure paths — no I/O, safe on any platform
p = PurePosixPath("a/b/c.txt")
print(p.parent, p.name, p.suffix)  # a/b c.txt .txt

w = PureWindowsPath(r"C:\Users\Ada\file.txt")
print(w.drive, w.root, w.parts)  # C: \ ('C:\\', 'Users', 'Ada', 'file.txt')

# Concrete paths — can hit the filesystem
q = Path("/tmp")  # PosixPath on Linux/macOS, WindowsPath on Windows
print(type(q).__name__, q.exists())
```

> In practice you almost always use `Path` (concrete) or `PurePath` only for
> manipulation without I/O. This lesson focuses on `Path`.

## 2. Constructing Paths

### 2.1 The `/` Operator and `joinpath`

The `/` operator is syntactic sugar for `joinpath`. Both handle separators
portably.

```python
from pathlib import Path

# Basic joining — the headline feature
base = Path("/home/ada")
p = base / "projects" / "app.py"
print(p)  # /home/ada/projects/app.py

# joinpath — equivalent, useful when parts are dynamic
parts = ["projects", "app.py"]
p2 = base.joinpath(*parts)
print(p2)  # /home/ada/projects/app.py

# Mixing strings and Paths
p3 = Path("/home") / Path("ada/projects") / "app.py"
print(p3)  # /home/ada/projects/app.py

# Absolute part resets — like os.path.join
print(Path("/a/b") / "/c/d")   # /c/d  — leading / discards left side
print(Path("/a/b") / "c/d")    # /a/b/c/d

# Trailing slashes are normalised
print(Path("/a/b/") / "c")     # /a/b/c

# Home directory
print(Path.home())             # /home/ada (or C:\Users\Ada)
print(Path("~/docs").expanduser())  # /home/ada/docs
```

```python
# Realistic: building a project layout
from pathlib import Path

PROJECT_ROOT = Path(__file__).parent if "__file__" in dir() else Path.cwd()
DATA_DIR = PROJECT_ROOT / "data"
CONFIG = DATA_DIR / "config.json"
LOG = PROJECT_ROOT / "logs" / "app.log"

print(PROJECT_ROOT, DATA_DIR, CONFIG, LOG)
```

### 2.2 Normalisation — No Automatic `..` Resolution

```python
p = Path("/a/b/../c/./d")
print(p)          # /a/b/../c/./d — NOT normalised!
print(p.resolve())  # /a/c/d — resolves symlinks and .. (touches filesystem)
# For pure lexical normalisation without I/O, join and inspect parts manually
```

> `Path` does **not** implicitly resolve `..` or `.` or symlinks. Use `resolve()`
> (see §3) when you need a canonical path.

## 3. Resolving, Absolute, and Canonical Paths

| Method | What it does | Touches filesystem? | Resolves symlinks? |
|--------|--------------|---------------------|--------------------|
| `Path.resolve(strict=False)` | Make absolute + resolve `..`, `.`, symlinks | Yes (reads symlinks) | Yes |
| `Path.absolute()` | Make absolute (prepend `cwd`) | No | No |
| `Path.expanduser()` | Expand `~` | No | No |

```python
from pathlib import Path

p = Path("a/b/../c")
print(p.absolute())   # /current/dir/a/b/../c  — just prepends cwd
print(p.resolve())    # /current/dir/a/c       — collapses .. and symlinks

# Symlink demo (POSIX)
import tempfile, os
with tempfile.TemporaryDirectory() as tmp:
    tmp = Path(tmp)
    real = tmp / "real.txt"
    real.write_text("hello", encoding="utf-8")
    link = tmp / "link.txt"
    link.symlink_to(real)

    print(link.resolve())    # /tmp/.../real.txt — follows link
    print(link.absolute())   # /tmp/.../link.txt — keeps link name
    print(link.is_symlink()) # True
    print(real.is_symlink()) # False

# strict=True raises if path does not exist (default strict=False since 3.6)
try:
    print(Path("nonexistent/foo").resolve(strict=True))
except FileNotFoundError as exc:
    print(f"strict resolve failed: {exc}")
```

> **When to use which:**
> - `resolve()` — when you need a canonical, comparison-ready path (e.g., checking
>   if two paths refer to the same file).
> - `absolute()` — when you just need an absolute path without I/O (rare; usually
>   `resolve()` is what you want).
> - Neither — when you want to preserve the user's original representation.

## 4. Inspecting Paths — Parts, Parents, Name, Suffix

```python
from pathlib import Path

p = Path("/home/ada/projects/app.tar.gz")
print(f"p        = {p}")
print(f"parts    = {p.parts}")      # ('/', 'home', 'ada', 'projects', 'app.tar.gz')
print(f"drive    = {p.drive}")      # '' on POSIX, 'C:' on Windows
print(f"root     = {p.root}")       # '/'
print(f"anchor   = {p.anchor}")     # '/'+ drive — '/' on POSIX
print(f"parent   = {p.parent}")     # /home/ada/projects
print(f"parents  = {list(p.parents)}")  # [/home/ada/projects, /home/ada, /home, /]
print(f"name     = {p.name}")       # app.tar.gz
print(f"stem     = {p.stem}")       # app.tar  (last suffix stripped)
print(f"suffix   = {p.suffix}")     # .gz
print(f"suffixes = {p.suffixes}")   # ['.tar', '.gz']
print(f"as_posix = {p.as_posix()}") # /home/ada/projects/app.tar.gz
print(f"as_uri   = {p.as_uri()}")   # file:///home/ada/projects/app.tar.gz

# Relative
print(p.relative_to("/home/ada"))         # projects/app.tar.gz
print(p.relative_to("/home/ada", walk_up=True))  # Python 3.12+: allows ..
print(p.is_relative_to("/home/ada"))      # True
print(p.is_relative_to("/tmp"))           # False
try:
    print(p.relative_to("/tmp"))
except ValueError as exc:
    print(f"not relative: {exc}")

# With transformations (return new Path, do not mutate)
print(p.with_name("other.zip"))    # /home/ada/projects/other.zip
print(p.with_stem("archive"))      # /home/ada/projects/archive.tar.gz (3.9+)
print(p.with_suffix(".zip"))       # /home/ada/projects/app.tar.zip
print(p.with_suffix(""))           # /home/ada/projects/app.tar — strip suffix
# with_suffix only replaces the LAST suffix:
print(Path("a.tar.gz").with_suffix(".zip"))  # a.tar.zip — not a.zip!
```

### Common Pitfall — `stem` With Multiple Suffixes

```python
p = Path("archive.tar.gz")
print(p.stem)      # archive.tar — only last suffix removed
print(p.suffix)    # .gz
# To strip all suffixes:
while p.suffix:
    p = p.with_suffix("")
print(p)  # archive  — but you lost the directory!
# Better: work on name
orig = Path("archive.tar.gz")
name = orig.name
for suf in orig.suffixes:
    if name.endswith(suf):
        name = name[: -len(suf)]
print(name)  # archive
```

## 5. Querying the Filesystem — `exists`, `is_file`, `is_dir`, etc.

| Method | Returns `True` if… | Follows symlink? |
|--------|--------------------|------------------|
| `exists()` | Path exists (file, dir, symlink, FIFO…) | Yes (use `is_symlink()` to test link itself) |
| `is_file()` | Regular file | Yes |
| `is_dir()` | Directory | Yes |
| `is_symlink()` | Symbolic link (even if broken) | No |
| `is_mount()` | Mount point (POSIX) | — |
| `is_socket()`, `is_fifo()`, `is_block_device()`, `is_char_device()` | Special file types | — |

```python
from pathlib import Path
import tempfile, os

with tempfile.TemporaryDirectory() as tmp:
    tmp = Path(tmp)
    (tmp / "file.txt").write_text("hi", encoding="utf-8")
    (tmp / "subdir").mkdir()
    (tmp / "link").symlink_to(tmp / "file.txt")
    (tmp / "broken").symlink_to(tmp / "nope")

    for name in ["file.txt", "subdir", "link", "broken", "missing"]:
        p = tmp / name
        print(f"{name:10s} exists={p.exists():5} is_file={p.is_file():5}"
              f" is_dir={p.is_dir():5} is_symlink={p.is_symlink():5}"
              f" lexists={p.is_symlink() or p.exists()}")
```

Output:

```
file.txt   exists=True  is_file=True  is_dir=False is_symlink=False lexists=True
subdir     exists=True  is_file=False is_dir=True  is_symlink=False lexists=True
link       exists=True  is_file=True  is_dir=False is_symlink=True  lexists=True
broken     exists=False is_file=False is_dir=False is_symlink=True  lexists=True
missing    exists=False is_file=False is_dir=False is_symlink=False lexists=False
```

> **Broken symlink trap:** `exists()` is `False` for a broken symlink, even though
> the link itself exists. Test `is_symlink()` first if you care about dangling
> links. `os.path.lexists` is `p.is_symlink() or p.exists()`.

### `stat()` and `lstat()`

```python
from pathlib import Path
import tempfile, stat

with tempfile.TemporaryDirectory() as tmp:
    p = Path(tmp) / "data.bin"
    p.write_bytes(b"hello world")
    p.chmod(0o644)

    st = p.stat()  # follows symlinks
    print(f"size={st.st_size} mode={oct(st.st_mode)} mtime={st.st_mtime}")
    print(f"is file? {stat.S_ISREG(st.st_mode)}")

    # lstat — do not follow symlinks (stat the link itself)
    link = Path(tmp) / "link"
    link.symlink_to(p)
    print(f"link lstat is symlink? {stat.S_ISLNK(link.lstat().st_mode)}")
    print(f"link stat   is symlink? {stat.S_ISLNK(link.stat().st_mode)}")  # False — follows to file
```

## 6. Reading and Writing — Convenience Methods

`Path` offers one-shot I/O for small files:

```python
from pathlib import Path
import tempfile, json

with tempfile.TemporaryDirectory() as tmp:
    p = Path(tmp) / "hello.txt"

    # Write
    p.write_text("héllo 🌍\n", encoding="utf-8", newline="\n")
    p.write_bytes(b"raw bytes\n")  # overwrites!

    # Read
    print(p.read_text(encoding="utf-8"))
    print(p.read_bytes())

    # JSON round-trip
    j = Path(tmp) / "data.json"
    j.write_text(json.dumps({"a": 1}, indent=2), encoding="utf-8")
    print(j.read_text(encoding="-if-8") if False else j.read_text(encoding="utf-8"))
```

| Method | Equivalent `open` | Notes |
|--------|-------------------|-------|
| `read_text(encoding, errors)` | `open(..., encoding=...).read()` | Whole file in memory |
| `write_text(data, encoding, errors, newline)` | `open(..., "w", ...).write(data)` | Truncates |
| `read_bytes()` | `open(..., "rb").read()` | — |
| `write_bytes(data)` | `open(..., "wb").write(data)` | — |

> **Do not use these for large files** — they slurp everything. Use `open()` +
> iteration for streaming. Also note `write_text`/`write_bytes` always truncate;
> there is no append variant — use `open(..., "a")` for appending.

## 7. Directory Operations — `iterdir`, `glob`, `rglob`, `mkdir`, `unlink`, `walk`

### 7.1 `iterdir()` — List Immediate Children

```python
from pathlib import Path
import tempfile

with tempfile.TemporaryDirectory() as tmp:
    base = Path(tmp)
    (base / "a.txt").write_text("a", encoding="utf-8")
    (base / "b.py").write_text("b", encoding="utf-8")
    (base / "subdir").mkdir()
    (base / "subdir" / "c.txt").write_text("c", encoding="utf-8")

    print("iterdir (non-recursive):")
    for child in base.iterdir():
        print(f"  {child.name} dir={child.is_dir()}")

    print("sorted iterdir:")
    for child in sorted(base.iterdir()):
        print(f"  {child}")
```

`iterdir()` yields `Path` objects, not strings, and is **not recursive**.

### 7.2 `glob` / `rglob` — Pattern Matching

```python
from pathlib import Path
import tempfile

with tempfile.TemporaryDirectory() as tmp:
    base = Path(tmp)
    (base / "a.txt").write_text("", encoding="utf-8")
    (base / "b.txt").write_text("", encoding="utf-8")
    (base / "c.py").write_text("", encoding="utf-8")
    (base / "sub").mkdir()
    (base / "sub" / "d.txt").write_text("", encoding="utf-8")
    (base / "sub" / "e.py").write_text("", encoding="utf-8")

    print("glob *.txt (top-level only):", sorted(base.glob("*.txt")))
    print("glob **/*.txt (recursive, explicit **):", sorted(base.glob("**/*.txt")))
    print("rglob *.txt (recursive shorthand):", sorted(base.rglob("*.txt")))
    print("rglob *.py:", sorted(base.rglob("*.py")))

    # Advanced patterns
    print("glob *.*:", sorted(base.glob("*.*")))
    # Note: glob does NOT match hidden files (dotfiles) by default on some patterns
    (base / ".hidden.txt").write_text("", encoding="utf-8")
    print("glob *.txt misses hidden:", sorted(base.glob("*.txt")))
    print("glob .*  finds hidden:", sorted(base.glob(".*")))
```

| Method | Recursion | Pattern relative to |
|--------|-----------|---------------------|
| `glob(pattern)` | Only if pattern contains `**` | The `Path` it is called on |
| `rglob(pattern)` | Always recursive | The `Path` it is called on (`**/` prepended) |

> **Performance:** `rglob` walks the entire subtree. For huge trees, prefer
> `glob("**/*.py")` with a specific pattern over `rglob("*")` + filtering.
>
> **Symlinks:** By default, `glob`/`rglob` do not follow directory symlinks
> (to avoid infinite loops). This is usually what you want.

### 7.3 `mkdir`, `unlink`, `rmdir`, `rename`, `replace`

```python
from pathlib import Path
import tempfile

with tempfile.TemporaryDirectory() as tmp:
    base = Path(tmp)

    # mkdir
    (base / "a" / "b" / "c").mkdir(parents=True, exist_ok=True)
    print((base / "a").exists())  # True — parents created

    # exist_ok=False (default) raises if exists
    try:
        (base / "a").mkdir()
    except FileExistsError as exc:
        print(f"mkdir exists: {exc}")

    # Parents without exist_ok
    try:
        (base / "x" / "y").mkdir()  # parents do not exist
    except FileNotFoundError as exc:
        print(f"mkdir parents missing: {exc}")

    # touch — create empty file or update mtime
    f = base / "a" / "hello.txt"
    f.touch(exist_ok=True)
    print(f.exists(), f.stat().st_size)  # True 0

    # unlink — delete file (or symlink)
    f.unlink()
    print(f.exists())  # False
    try:
        f.unlink()  # missing_ok=False by default
    except FileNotFoundError as exc:
        print(f"unlink missing: {exc}")
    f.touch()
    f.unlink(missing_ok=True)  # no error even if absent (Python 3.8+)

    # rmdir — delete EMPTY directory
    empty = base / "empty_dir"
    empty.mkdir()
    empty.rmdir()
    print(empty.exists())  # False
    try:
        (base / "a").rmdir()  # not empty
    except OSError as exc:
        print(f"rmdir not empty: {exc}")

    # rename / replace
    src = base / "src.txt"
    dst = base / "dst.txt"
    src.write_text("hello", encoding="utf-8")
    src.rename(dst)  # may fail if dst exists on some platforms
    print(dst.read_text(encoding="utf-8"), src.exists())

    # replace — atomic overwrite, always succeeds if src exists
    src.write_text("new", encoding="utf-8")
    src.replace(dst)  # overwrites dst atomically (os.replace)
    print(dst.read_text(encoding="utf-8"))

    # symlink_to
    link = base / "link.txt"
    link.symlink_to(dst)
    print(link.is_symlink(), link.read_text(encoding="utf-8"))

    # chmod, lchmod
    dst.chmod(0o644)
    print(oct(dst.stat().st_mode)[-3:])
```

| Method | Behaviour on existing target |
|--------|------------------------------|
| `rename(target)` | May raise `FileExistsError` (Windows) or silently replace (POSIX) — **not portable** |
| `replace(target)` | Atomically replaces — **portable, prefer `replace`** |

### 7.4 Recursive Deletion — `shutil.rmtree`

`Path` has no recursive `rm -rf`. Use `shutil.rmtree`:

```python
import shutil
from pathlib import Path
import tempfile

with tempfile.TemporaryDirectory() as tmp:
    base = Path(tmp) / "tree"
    (base / "a" / "b").mkdir(parents=True)
    (base / "a" / "b" / "file.txt").write_text("x", encoding="utf-8")
    shutil.rmtree(base)
    print(base.exists())  # False
```

### 7.5 Walking — `Path.walk()` (Python 3.12+) vs `os.walk`

```python
from pathlib import Path
import tempfile, os

with tempfile.TemporaryDirectory() as tmp:
    base = Path(tmp)
    (base / "a").mkdir()
    (base / "a" / "file1.txt").write_text("", encoding="utf-8")
    (base / "b" / "c").mkdir(parents=True)
    (base / "b" / "c" / "file2.txt").write_text("", encoding="utf-8")

    # Python 3.12+: Path.walk — yields (dirpath, dirnames, filenames)
    # Similar to os.walk but dirpath is a Path
    if hasattr(Path, "walk"):
        for dirpath, dirnames, filenames in base.walk():
            print(f"walk: {dirpath} dirs={dirnames} files={filenames}")
            # Modify dirnames in-place to prune traversal:
            # dirnames[:] = [d for d in dirnames if d != "b"]

    # Portable alternative — os.walk accepts Path
    for dirpath, dirnames, filenames in os.walk(base):
        print(f"os.walk: {dirpath} dirs={dirnames} files={filenames}")

    # Manual recursion with iterdir — full control, no hidden symlink following
    def walk_manual(p: Path):
        for child in p.iterdir():
            if child.is_dir() and not child.is_symlink():
                yield from walk_manual(child)
            elif child.is_file():
                yield child

    print("manual:", list(walk_manual(base)))
```

## 8. `pathlib` vs `os.path` — Migration Guide

| Task | `os.path` | `pathlib` |
|------|-----------|-----------|
| Join | `os.path.join(a, b, c)` | `Path(a) / b / c` or `Path(a).joinpath(b, c)` |
| Absolute | `os.path.abspath(p)` | `Path(p).resolve()` / `Path(p).absolute()` |
| Basename | `os.path.basename(p)` | `Path(p).name` |
| Dirname | `os.path.dirname(p)` | `str(Path(p).parent)` or `Path(p).parent` |
| Splitext | `os.path.splitext(p)` | `Path(p).suffix`, `Path(p).stem`, `Path(p).suffixes` |
| Split | `os.path.split(p)` | `Path(p).parent, Path(p).name` |
| Exists | `os.path.exists(p)` | `Path(p).exists()` |
| Is file/dir | `os.path.isfile(p)` | `Path(p).is_file()` |
| Expand user | `os.path.expanduser(p)` | `Path(p).expanduser()` |
| Expand vars | `os.path.expandvars(p)` | `os.path.expandvars(os.fspath(Path(p)))` — no pathlib equiv |
| Common path | `os.path.commonpath(paths)` | No direct equiv — use `os.path.commonpath` |
| Normpath | `os.path.normpath(p)` | `Path(p).resolve()` (but resolves symlinks) |
| Relpath | `os.path.relpath(p, start)` | `Path(p).relative_to(start)` (stricter) |
| List dir | `os.listdir(p)` | `list(Path(p).iterdir())` |
| Glob | `glob.glob(pattern)` | `Path(".").glob(pattern)` |
| Stat | `os.stat(p)` | `Path(p).stat()` |
| Open | `open(p)` | `open(p)` or `Path(p).read_text()` |

> All stdlib functions that accept `str` paths also accept `Path` via
> `os.fspath()`. You can gradually migrate: `open(Path("file.txt"))` works.

## 9. The `os.PathLike` Protocol and `os.fspath`

```python
from pathlib import Path
import os

p = Path("/tmp/demo.txt")

# Any os.PathLike can be passed to open, os.stat, etc.
print(isinstance(p, os.PathLike))  # True
print(os.fspath(p))                # '/tmp/demo.txt' — str
print(os.fsencode(p))              # b'/tmp/demo.txt' — bytes

# Custom PathLike — pathlib is not the only one
class MyPath:
    def __fspath__(self) -> str:
        return "/tmp/custom"

print(os.fspath(MyPath()))  # /tmp/custom
open(MyPath())  # works if file exists

# Type hints
from pathlib import Path
from os import PathLike

def process(path: Path | PathLike[str]) -> None:
    p = Path(path)  # normalise to Path for method access
    print(p.resolve())
```

## 10. Realistic End-to-End Examples

### Example 1: Project Scaffolding

```python
from pathlib import Path

def scaffold_project(root: Path, name: str) -> Path:
    """Create a standard Python project layout."""
    project = root / name
    project.mkdir(parents=True, exist_ok=False)  # fail if exists — use x semantics
    (project / "src" / name).mkdir(parents=True)
    (project / "tests").mkdir()
    (project / "src" / name / "__init__.py").write_text("", encoding="utf-8")
    (project / "README.md").write_text(f"# {name}\n", encoding="utf-8")
    (project / "pyproject.toml").write_text('[build-system]\nrequires = ["setuptools"]\n', encoding="utf-8")
    return project

import tempfile
with tempfile.TemporaryDirectory() as tmp:
    proj = scaffold_project(Path(tmp), "myapp")
    print("\n".join(str(p.relative_to(proj)) for p in sorted(proj.rglob("*"))))
```

### Example 2: Finding All Python Files Modified in Last 7 Days

```python
from pathlib import Path
import time

def recent_python_files(root: Path, days: int = 7) -> list[Path]:
    cutoff = time.time() - days * 86400
    return [
        p for p in root.rglob("*.py")
        if p.is_file() and p.stat().st_mtime > cutoff
    ]

# Usage: recent_python_files(Path.cwd())
```

### Example 3: Safe File Finder With Error Handling

```python
from pathlib import Path

def find_files(root: Path, pattern: str = "*.log") -> list[Path]:
    """Find files matching pattern, skipping unreadable directories."""
    found: list[Path] = []
    # Use os.walk for fine-grained error handling; pathlib glob has no onerror
    import os
    for dirpath, dirnames, filenames in os.walk(root, onerror=lambda e: print(f"skip {e}")):
        # pathlib-style filtering inside os.walk
        for name in filenames:
            p = Path(dirpath) / name
            if p.match(pattern):
                found.append(p)
    return found

# Path.match — matches from the right, with glob semantics
print(Path("a/b/c.py").match("*.py"))    # True
print(Path("a/b/c.py").match("b/*.py"))  # True
print(Path("a/b/c.py").match("a/*.py"))  # False — needs **
print(Path("a/b/c.py").match("**/*.py")) # True
```

### Example 4: Atomic Config Writer Using `pathlib` + `tempfile`

```python
from pathlib import Path
import tempfile, os, json

def atomic_write_json(path: Path, data: dict) -> None:
    fd, tmp = tempfile.mkstemp(dir=str(path.parent), suffix=".tmp")
    try:
        with os.fdopen(fd, "w", encoding="utf-8", newline="\n") as f:
            json.dump(data, f, indent=2)
            f.write("\n")
        Path(tmp).replace(path)  # atomic
    finally:
        # Clean up if replace didn't happen (exception before replace)
        try:
            Path(tmp).unlink(missing_ok=True)
        except OSError:
            pass

import tempfile
with tempfile.TemporaryDirectory() as tmp:
    cfg = Path(tmp) / "config.json"
    atomic_write_json(cfg, {"version": 1, "name": "demo"})
    print(cfg.read_text(encoding="utf-8"))
```

## 11. Pitfalls and Edge Cases

| Pitfall | Symptom | Fix |
|---------|---------|-----|
| `Path("a") / "/b"` discards left | Unexpected absolute | Avoid joining with absolute parts; check `Path.is_absolute()` |
| `resolve()` vs `absolute()` confusion | Symlinks not resolved or extra I/O | Use `resolve()` for canonical, `absolute()` only when you must avoid I/O |
| `write_text` truncates | Data loss if you meant append | Use `open(p, "a")` or `read_text` + `write_text` |
| `glob("*.py")` not recursive | Misses subdirectories | Use `rglob("*.py")` or `glob("**/*.py")` |
| `relative_to` raises `ValueError` | Crash on unrelated paths | Use `is_relative_to` first, or `os.path.relpath` for `..` support |
| `with_suffix` only replaces last suffix | `a.tar.gz` → `a.tar.zip` | Loop over `suffixes` or manipulate `name` |
| `exists()` false for broken symlink | Think link is missing | Check `is_symlink()` or `lexists` |
| Mixing `str` and `Path` in APIs | Some APIs need `str` | Use `os.fspath(p)` to coerce |
| `iterdir` order is arbitrary | Non-deterministic output | `sorted(p.iterdir())` |
| `Path.match("*.py")` matches any depth with `**`? | Surprising `False` | Remember `match` is from the right; use `**/*.py` for deep |

## Summary

- `Path` is an object-oriented, platform-aware replacement for `os.path` string
  manipulation. Use `/` and `joinpath` to build paths.
- Distinguish `PurePath` (no I/O) from `Path` (concrete, I/O-capable).
- `resolve()` canonicalises (absolute + symlinks + `..`); `absolute()` just
  prepends `cwd`; `expanduser()` expands `~`.
- Inspect with `parts`, `parent`, `name`, `stem`, `suffix`/`suffixes`,
  `relative_to`, `with_name`/`with_suffix`.
- Query with `exists`/`is_file`/`is_dir`/`is_symlink`/`stat`; beware broken
  symlinks (`exists()` is `False`).
- One-shot I/O via `read_text`/`write_text`/`read_bytes`/`write_bytes`; streaming
  via `open(path)`.
- Iterate with `iterdir` (flat), `glob`/`rglob` (pattern), `walk` (3.12+).
- Mutate with `mkdir`/`touch`/`unlink`/`rmdir`/`rename`/`replace`/`symlink_to`/
  `chmod`; recursive delete via `shutil.rmtree`.
- Most stdlib functions accept `Path` via `os.PathLike` / `os.fspath`.
