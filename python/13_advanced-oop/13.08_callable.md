# 13.08 Callable Objects: __call__

## Functions Are Not Special — Callables Are a Role

In Python, a **callable** is any object whose type has a `__call__` method. Functions just happen to be callable objects whose `__call__` is wired in C. Nothing stops your own instances from being called with `obj(...)`.

```python
def func(x): return x * 2
class Functor:
    def __call__(self, x): return x * 2

print(callable(func))    # True — functions implement __call__
print(callable(Functor()))  # True — our instance implements __call__
print(callable(42))      # False — int has no __call__

# Two invocations that look identical but dispatch differently:
print(func(5))            # type(func).__call__(func, 5) — C-level function call
f = Functor()
print(f(5))               # type(f).__call__(f, 5)  — i.e. Functor.__call__(f, 5)

# Introspection:
import inspect
print(inspect.isfunction(func))   # True — callable but specifically a function
print(inspect.isfunction(Functor())) # False — callable but not a function
print(callable(Functor))          # True — the class itself is callable via type.__call__ (13.02)
```

> **Mental model:** A callable instance is a **function with memory**. It bundles code (`__call__`) with state (instance attributes). Use it whenever a plain function would need external mutable state or configuration.

### How Dispatch Works

```python
# obj(*args, **kwargs) desugars to:
#   type(obj).__call__(obj, *args, **kwargs)
# Lookup is on the type, not the instance — shadowing __call__ on an instance does NOT make len() changes affect calls:

class Demo:
    def __call__(self): return "type-level"

d = Demo()
print(d())  # type-level
d.__call__ = lambda: "instance-shadowing"
print(d())  # still type-level — instance attribute ignored!
print(d.__call__())  # instance-shadowing — explicit attribute access finds instance shadowing
# To change behavior, patch the class: Demo.__call__ = lambda self: "patched"
```

## Why Use Callable Objects? Four Motivations

| Motivation | Plain function fails because | Callable object wins |
|------------|-----------------------------|---------------------|
| **State** | Closure or `global` needed; mutable default traps | Encapsulated `self.state` with clear lifecycle |
| **Configuration** | Factory functions + `functools.partial` possible but opaque | `self.config` explicit, inspectable, documentable |
| **Polymorphism / Strategy** | Functions are not interchangeable with objects in a framework that expects `obj.method` | Callable instances fit into strategy interfaces and can share base class |
| **Composition / Pipeline** | Nested closures are hard to debug and test | Callable objects compose (`pipeline = Add(2)(Mul(3))`), have `__repr__`, can be serialized |

## Progression: From Closure to Callable — When Each Is Appropriate

### 1. Closure

```python
def make_counter(start=0):
    count = start
    def inc(step=1):
        nonlocal count
        count += step
        return count
    return inc

c = make_counter(10)
print(c(), c(5))  # 11 16
# Pros: concise; Cons: state invisible, can't introspect count without calling; testing requires execution

# Callable class equivalent — explicit, testable:
class Counter:
    """Stateful callable counter — inspectable, resettable."""
    def __init__(self, start=0):
        self.value = start
    def __call__(self, step=1) -> int:
        self.value += step
        return self.value
    def reset(self, to=0): self.value = to
    def __repr__(self): return f"Counter(value={self.value})"

cc = Counter(10)
print(cc(), cc(5))  # 11 16
print(cc.value)     # 16 — inspectable without side-effect
cc.reset()
print(cc)           # Counter(value=0)

# When closure wins: trivial state, one-off lambdas.
# When callable class wins: non-trivial state, lifecycle methods, debuggability.
```

### 2. Configuration / Currying

```python
# Function via partial
import functools

def power(base, exp): return base ** exp
square = functools.partial(power, exp=2)
print(square(5))  # 25 — but repr is opaque: functools.partial(<func>, exp=2)

# Callable class — explicit configuration and repr
class Power:
    def __init__(self, exp: int):
        if exp < 0: raise ValueError("exp must be >= 0")
        self.exp = exp
    def __call__(self, base: float) -> float:
        return base ** self.exp
    def __repr__(self): return f"Power(exp={self.exp})"

square2 = Power(2)
cube = Power(3)
print(square2(5), cube(2))  # 25 8
print(square2)              # Power(exp=2)
# Power instances are self-documenting and validate eagerly.

# Realistic: pricing rule with tax and discount configuration
class PriceCalculator:
    """Callable pricing strategy — encapsulates rules, testable in isolation."""
    def __init__(self, tax_rate: float = 0.08, discount: float = 0.0):
        if not 0 <= discount < 1: raise ValueError("discount in [0,1)")
        self.tax_rate, self.discount = tax_rate, discount
    def __call__(self, subtotal: float) -> float:
        discounted = subtotal * (1 - self.discount)
        return round(discounted * (1 + self.tax_rate), 2)
    def __repr__(self): return f"PriceCalculator(tax={self.tax_rate}, discount={self.discount})"

std_price = PriceCalculator()
vip_price = PriceCalculator(tax_rate=0.08, discount=0.1)
print(std_price(100), vip_price(100))  # 108.0 97.2
```

### 3. State + Configuration Together — Retry / Throttle

```python
import time, functools

class Retry:
    """Callable decorator factory — state = attempts counter, config = max tries + backoff."""
    def __init__(self, attempts: int = 3, backoff: float = 0.1):
        if attempts < 1: raise ValueError("attempts >= 1")
        self.attempts, self.backoff = attempts, backoff

    def __call__(self, func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            delay = self.backoff
            for n in range(self.attempts):
                try:
                    return func(*args, **kwargs)
                except Exception as e:
                    if n == self.attempts - 1: raise
                    print(f"[retry {n+1}/{self.attempts}] {e!r}, sleeping {delay:.2f}s")
                    time.sleep(delay)
                    delay *= 2
            # unreachable
        return wrapper
    def __repr__(self): return f"Retry(attempts={self.attempts}, backoff={self.backoff})"

@Retry(attempts=3, backoff=0.01)
def flaky(x):
    import random
    if random.random() < 0.7: raise RuntimeError("transient")
    return x * 2

# Callable instance is ALSO the decorator factory — no extra function layer needed.

# Throttle as callable:
class Throttle:
    """Rate limiter — callable gate, state = last_called timestamp."""
    def __init__(self, rate_per_sec: float):
        self.min_interval = 1.0 / rate_per_sec
        self._last = 0.0
    def __call__(self, func):
        @functools.wraps(func)
        def wrapper(*a, **kw):
            now = time.monotonic()
            wait = self._last + self.min_interval - now
            if wait > 0: time.sleep(wait)
            result = func(*a, **kw)
            self._last = time.monotonic()
            return result
        return wrapper

@Throttle(rate_per_sec=2)
def polled(): print("tick")
# polled() will sleep to enforce max 2 calls/sec.
```

## `__call__` vs Closures vs `functools.partial` — Decision Table

| Need | Prefer | Why |
|------|--------|-----|
| Single variable capture, no mutation | `lambda` / closure | Concise |
| Mutable counter or accumulator | `Counter` callable class | Explicit state, resettable, testable |
| Pre-fill arguments of an existing function | `functools.partial` | Intended purpose; keeps signature inspectable via `partial.func`/`args`/`keywords` |
| Decorator with arguments (`@retry(attempts=5)`) | Callable class (`Retry.__call__(self, func)`) or closure | Both work; class scales to complex config and state |
| Interchangeable strategy (pass policy to algorithm) | Callable class with shared base / Protocol | Polymorphic, documents expected signature |
| Memoization / caching | `functools.lru_cache` or `__call__` with `self._cache` | Depends on lifetime — lru_cache for function, callable class when cache belongs to object lifecycle |

```python
import functools, inspect

# partial keeps inspectability:
def greet(name, greeting="hello"): return f"{greeting}, {name}"
partial_greet = functools.partial(greet, greeting="hi")
print(partial_greet.func, partial_greet.args, partial_greet.keywords)
print(inspect.signature(partial_greet))  # (name, *, greeting='hello') — still useful
print(partial_greet("Alice"))             # hi, Alice

# Callable class also inspectable via signature of __call__:
class Greeter:
    def __init__(self, greeting="hello"): self.greeting = greeting
    def __call__(self, name: str) -> str: return f"{self.greeting}, {name}"

g = Greeter("hi")
print(inspect.signature(g))   # (name: str) -> str — introspectable via type(g).__call__
print(g("Alice"))
```

## Bound Methods Are Callables: `__call__` vs Method Dispatch

Every bound method is itself a callable whose `__call__` forwards to the underlying function with `self` pre-bound:

```python
class Logger:
    def log(self, msg: str) -> None: print(f"LOG: {msg}")

logger = Logger()
bound = logger.log           # bound method: Logger.log bound to logger
print(callable(bound))       # True
print(type(bound))           # <class 'method'>
print(bound)                 # <bound method Logger.log of <Logger object>>
# Calling bound.log(msg) is effectively Logger.log(logger, msg)

# Under the hood (simplified):
# type(bound).__call__(bound, msg)  ->  Logger.log.__get__(logger, Logger) -> bound -> __call__ -> log

# Contrast callable instance:
class LogCallable:
    def __init__(self, prefix="LOG"): self.prefix = prefix
    def __call__(self, msg): print(f"{self.prefix}: {msg}")

lc = LogCallable()
print(callable(lc))          # True — via __call__
print(type(lc))              # <class '__main__.LogCallable'>

# When to choose bound method vs callable instance:
# - Bound method: behavior IS identity (logging belongs to Logger instance)
# - Callable instance: object IS behavior (strategy that can be passed as a function)
#   e.g., priority_queue.push(Prioritizer(urgency=5)) vs queue.push(logger.log) — similar but semantically different.
```

## Realistic Examples: Pipelines, Regularizers, Validators

### Example 1: Data Transformation Pipeline — Composing Callables

```python
from typing import Callable

class Pipeline:
    """Composable pipeline of callables — each step transforms data, pipeline itself is callable."""
    def __init__(self, *steps: Callable):
        self.steps = list(steps)

    def add(self, step: Callable) -> "Pipeline":
        self.steps.append(step)
        return self

    def __call__(self, data):
        for step in self.steps:
            data = step(data)
        return data

    def __repr__(self):
        names = [getattr(s, "__name__", repr(s)) for s in self.steps]
        return f"Pipeline({', '.join(names)})"

    # Optional operator overload: pipeline composition via |
    def __or__(self, other: Callable) -> "Pipeline":
        return Pipeline(*self.steps, other)

def strip(s: str) -> str: return s.strip()
def lower(s: str) -> str: return s.lower()

class Replace:
    """Stateful transformer — replaces occurrences, keeps count."""
    def __init__(self, old: str, new: str):
        self.old, self.new = old, new
        self.count = 0
    def __call__(self, s: str) -> str:
        result = s.replace(self.old, self.new)
        # Track how many replacements happened:
        self.count += s.count(self.old)
        return result
    def __repr__(self): return f"Replace({self.old!r}->{self.new!r})"

pipeline = Pipeline(strip, lower, Replace("hello", "hi"), Replace("world", "earth"))
print(pipeline("  Hello World  "))    # hi earth — via pipeline __call__
print(pipeline.steps[2].count)        # 1 — stateful step tracks usage
print(pipeline.steps[3].count)        # 1
print(list(map(pipeline, ["  Hello Mars  ", "world hello"])) )  # ['hi mars', 'earth hi']

# Composed via |:
trim_lower = Pipeline(strip) | lower
print(trim_lower("  ABC  "))  # abc
```

### Example 2: ML Regularizer / Loss-style Callable Strategy

```python
import math

class L2Regularizer:
    """L2 penalty — callable that computes lambda * ||weights||^2, tracks call count for logging."""
    def __init__(self, lmbda: float = 0.01):
        if lmbda < 0: raise ValueError("lambda >= 0")
        self.lmbda = lmbda
        self.calls = 0

    def __call__(self, weights: list[float]) -> float:
        self.calls += 1
        return self.lmbda * sum(w*w for w in weights)

    def gradient(self, weights: list[float]) -> list[float]:
        # Not a __call__ — separate method on same object, showing why callable class beats function:
        return [2 * self.lmbda * w for w in weights]

    def __repr__(self): return f"L2Regularizer(lambda={self.lmbda})"

class L1Regularizer:
    def __init__(self, lmbda: float = 0.01): self.lmbda, self.calls = lmbda, 0
    def __call__(self, weights: list[float]) -> float:
        self.calls += 1
        return self.lmbda * sum(abs(w) for w in weights)
    def gradient(self, weights: list[float]) -> list[float]:
        return [self.lmbda * (1 if w > 0 else -1 if w < 0 else 0) for w in weights]
    def __repr__(self): return f"L1Regularizer(lambda={self.lmbda})"

# Strategy injected into a training loop:
def train(weights: list[float], regularizer) -> float:
    loss_data = sum(w*w for w in weights)  # dummy data loss
    loss_reg = regularizer(weights)        # dispatch to __call__ — agnostic to L1/L2
    return loss_data + loss_reg

weights = [0.5, -1.0, 0.2]
print(train(weights, L2Regularizer(0.1)))  # data + l2
print(train(weights, L1Regularizer(0.1)))  # data + l1 — same call site, different policy

# This is Strategy pattern without boilerplate — regularizer IS the policy callable.
# Alternative as Protocol:
from typing import Protocol

class Regularizer(Protocol):
    def __call__(self, weights: list[float]) -> float: ...
    def gradient(self, weights: list[float]) -> list[float]: ...
```

### Example 3: Predicate Builder — Callable That Returns Callables

```python
class FieldEquals:
    """Predicate factory — FieldEquals('status','shipped') returns a callable that tests dicts."""
    def __init__(self, field: str, expected):
        self.field, self.expected = field, expected
    def __call__(self, obj: dict) -> bool:
        return obj.get(self.field) == self.expected
    def __repr__(self): return f"FieldEquals({self.field!r},{self.expected!r})"
    # Enable composition:
    def __and__(self, other): return AllOf(self, other)
    def __or__(self, other): return AnyOf(self, other)
    def __invert__(self): return Not(self)

class AllOf:
    def __init__(self, *preds): self.preds = preds
    def __call__(self, obj): return all(p(obj) for p in self.preds)
    def __repr__(self): return f"AllOf({self.preds!r})"

class AnyOf:
    def __init__(self, *preds): self.preds = preds
    def __call__(self, obj): return any(p(obj) for p in self.preds)
    def __repr__(self): return f"AnyOf({self.preds!r})"

class Not:
    def __init__(self, pred): self.pred = pred
    def __call__(self, obj): return not self.pred(obj)
    def __repr__(self): return f"Not({self.pred!r})"

orders = [{"status":"shipped","total":100},{"status":"pending","total":5},{"status":"shipped","total":5}]
shipped = FieldEquals("status","shipped")
high_value = FieldEquals("total",100)  # toy — use lambda for range tests
print(list(filter(shipped, orders)))           # 2 orders
print(list(filter(shipped & high_value, orders)))  # 1 order
print(list(filter(~shipped, orders)))          # 1 order
```

### Example 4: Event Emitter with Callable Listeners

```python
class Event:
    def __init__(self): self._listeners: list[Callable] = []
    def connect(self, listener: Callable) -> Callable:
        self._listeners.append(listener)
        return listener  # allow decorator use: @event.connect
    def disconnect(self, listener): self._listeners.remove(listener)
    def emit(self, *args, **kwargs):
        for listener in list(self._listeners):
            listener(*args, **kwargs)
    def __len__(self): return len(self._listeners)

on_data = Event()

@on_data.connect
def log_event(data): print(f"event: {data}")

class StatsCollector:
    """Callable listener that accumulates state across emits."""
    def __init__(self): self.count = 0; self.data = []
    def __call__(self, data): self.count += 1; self.data.append(data)
    def __repr__(self): return f"StatsCollector(count={self.count})"

stats = StatsCollector()
on_data.connect(stats)
on_data.emit({"id": 1})
on_data.emit({"id": 2})
print(stats)           # StatsCollector(count=2)
print(stats.data)      # [{'id': 1}, {'id': 2}]
```

## `__call__` Inheritance and Chaining to Parent

```python
class BaseHandler:
    def __call__(self, request: dict) -> dict:
        print(f"Base handling {request}")
        return {"status": "base"}

class AuditedHandler(BaseHandler):
    def __call__(self, request: dict) -> dict:
        print(f"[audit] request={request!r}")
        # Chain to parent's callable behavior
        response = super().__call__(request)
        print(f"[audit] response={response!r}")
        return response

h = AuditedHandler()
print(h({"path": "/"}))  # audit logs wrap base behavior
```

## Introspection & Signatures

A callable class should expose a correct signature so `inspect`, `functools.wraps`, and IDE hints work:

```python
import inspect, functools

class Multiplier:
    def __call__(self, value: float, factor: float = 1.0) -> float:
        return value * factor

m = Multiplier()
print(inspect.signature(m))     # (value: float, factor: float = 1.0) -> float
print(callable(m))              # True
print(hasattr(m, "__call__"))   # True
print(m.__call__)               # <bound method Multiplier.__call__ of <Multiplier>>

# When a callable wraps another function, preserve metadata:
class LoggedCall:
    def __init__(self, func):
        self.func = func
        functools.update_wrapper(self, func)  # copies __name__, __doc__, __annotations__, __wrapped__

    def __call__(self, *args, **kwargs):
        print(f"calling {self.func.__name__}({args}, {kwargs})")
        return self.func(*args, **kwargs)

@LoggedCall
def add(a, b): """Add two numbers."""; return a+b

print(add.__name__, add.__doc__)                # add Add two numbers.
print(inspect.signature(add))                   # (a, b) — but signature is wrapper's unless we proxy it
# To proxy wrapped signature, expose __wrapped__ and use functools.wraps handling or define __signature__:
# In decorator frameworks, set: self.__signature__ = inspect.signature(func) may be needed.

# Python 3.4+ inspect.signature follows __wrapped__ chain automatically for functions;
# for callable objects you may need to define __wrapped__ or __signature__ manually.
```

## Edge Cases & Pitfalls

| Pitfall | Symptom | Fix |
|---------|---------|-----|
| `__call__` defined but missing `self` | `TypeError: __call__() takes 1 positional arg but 2 were given` | Always `def __call__(self, ...):` |
| Shadowing `__call__` on instance | `obj()` ignores instance attribute | Patch on the class, not the instance, or use attribute that `__call__` delegates to |
| Making a bare class callable vs instance callable | `Class()(...)` vs `Class(...)` confusion (`__new__` vs `__call__`) | Remember: `Class(...)` is `type.__call__`; `instance(...)` is `instance.__call__` |
| Over-using callable objects where a function suffices | Harder to read, unnecessary state containers | Prefer `def func` for stateless behavior |
| Not defining `__repr__` on callable stateful object | Logs show `<Callable at 0x...>` with no clue about config | Provide `__repr__` including key config and state if bounded |
| Forgetting `functools.update_wrapper` when wrapping | `help(wrapper)` shows wrapper docs, not wrapped func | `functools.update_wrapper(self, func)` or `@functools.wraps` |
| Recursively callable that returns self | Infinite `x()()()...` chain never terminates | Document chaining contract; optionally limit depth |

## Performance Notes

*   `obj(*args)` via `__call__` adds one Python method dispatch compared to a plain function call. Micro-benchmark: plain function `f(1)` ~70 ns, callable `c(1)` via `__call__` ~90–110 ns on CPython 3.11+.Negligible outside tight loops.
*   If `__call__` is on a hot path (per-element in a million-item map), consider whether a vectorized approach or plain function eliminates the overhead. Profile before optimizing.
*   Callable pipelines that chain many `__call__` steps allocate intermediate results per step. Prefer fusing steps or using generator pipelines for streaming data.

## Checklist: Should You Make It Callable?

1.  Does the object represent an *action* or *calculation* more than an entity? (`PriceRule`, `Filter`, `RetryPolicy`) → callable is natural.
2.  Does it need mutable state or config that influences the call? → callable beats closure.
3.  Is it interchangeable with plain functions in the call site (`map`, `filter`, strategy injection)? → callable satisfies `Callable` Protocol.
4.  Have you provided `__repr__` exposing config?
5.  Is `inspect.signature(instance)` meaningful? Test it.
6.  Have you used `functools.update_wrapper` if you wrap another callable?

## Advanced Patterns: Caching, Memoization, and Decorator Factories Revisited

### Memoized Callable With LRU Semantics

```python
from collections import OrderedDict

class Memoized:
    def __init__(self, func, maxsize: int = 128):
        self.func = func
        self.maxsize = maxsize
        self._cache: OrderedDict[tuple, object] = OrderedDict()
        self.hits = self.misses = 0
        import functools
        functools.update_wrapper(self, func)

    def __call__(self, *args, **kwargs):
        key = (args, tuple(sorted(kwargs.items())))
        if key in self._cache:
            self.hits += 1
            self._cache.move_to_end(key)
            return self._cache[key]
        self.misses += 1
        result = self.func(*args, **kwargs)
        self._cache[key] = result
        if len(self._cache) > self.maxsize:
            self._cache.popitem(last=False)
        return result

@Memoized
def fib(n: int) -> int:
    if n < 2: return n
    return fib(n-1) + fib(n-2)

print(fib(10))
print(fib.cache_info())
```

### Callable As Strategy Registry

```python
class Dispatcher:
    def __init__(self):
        self._handlers: dict[type, callable] = {}
    def register(self, typ: type):
        def decorator(func):
            self._handlers[typ] = func
            return func
        return decorator
    def __call__(self, obj):
        for typ, handler in self._handlers.items():
            if isinstance(obj, typ):
                return handler(obj)
        raise TypeError(f"No handler for {type(obj).__name__}")

dispatch = Dispatcher()

@dispatch.register(int)
def _handle_int(x: int): return f"int:{x*2}"
@dispatch.register(str)
def _handle_str(s: str): return f"str:{s.upper()}"

print(dispatch(42))
print(dispatch("hello"))
```
