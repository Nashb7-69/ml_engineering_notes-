# 01.5 Strings

> **Mental model:** A Python `str` is an *immutable sequence of Unicode code points* — not bytes, not characters in the C sense. Every string operation that appears to "modify" a string actually creates a new one. Encoding translates between the world of text (`str`) and the world of bytes (`bytes`) — and confusing the two is the most common source of string bugs.

---

## 1. What a `str` Really Is

In Python 3, `str` is always Unicode. Internally (CPython's PEP 393 "flexible string representation"), it is stored as an array of code points using 1, 2, or 4 bytes per character depending on the widest character — but this is invisible to you. What you see is an immutable, iterable sequence.

```python
s = "hello"
print(type(s))       # <class 'str'>
print(len(s))        # 5 — number of code points, NOT bytes
print(s[0])          # 'h' — indexing returns a one-character str (no char type!)
print(type(s[0]))    # <class 'str'>
print(s[1:4])        # 'ell' — slicing returns a new str

# Strings are sequences — all sequence operations work
print("e" in s)      # True — membership
print("ell" in s)    # True — substring search
print(s + " world")  # 'hello world' — concatenation (creates new str)
print(s * 3)         # 'hellohellohello' — repetition
for ch in s:
    print(ch, end=" ")  # h e l l o — iteration over code points
print()

# No separate `char` type — a "character" is just a str of length 1
ch = "A"
print(len(ch))       # 1
print(ord(ch))       # 65 — code point value
print(chr(65))       # 'A' — code point → str
```

### Immutability — Every "Modification" Creates a New String

```python
s = "hello"
# s[0] = "H"  # TypeError: 'str' object does not support item assignment

# All string methods return NEW strings — the original is unchanged
original = "  hello world  "
print(original.strip())    # 'hello world' — new string
print(original)            # '  hello world  ' — original untouched
print(id(original) != id(original.strip()))  # True — different objects

# Reassignment rebinds the name (see Lesson 01.1)
s = "hello"
old_id = id(s)
s = s.upper()       # new string, name rebound
print(s)            # HELLO
print(id(s) == old_id)  # False — different object

# Building strings by repeated += in a loop creates many intermediates
# For large constructions, use str.join() instead (see Methods section)
```

## 2. Quoting — Single, Double, Triple

Python treats `'...'` and `"..."` identically — choose whichever avoids escaping.

```python
# Single and double quotes — same type, pick the one that minimises escaping
single = 'hello'
double = "hello"
print(single == double)  # True
print(type(single) is type(double))  # True

# Choose quotes to avoid escaping the other kind
msg1 = "It's a beautiful day"    # double outside → single inside needs no escape
msg2 = 'He said "hello"'         # single outside → double inside needs no escape
msg3 = 'It\'s a "beautiful" day' # escape when both appear
print(msg1)
print(msg2)
print(msg3)

# Triple quotes — multi-line strings, often used for docstrings
multi = """This is a
multi-line string.
It preserves line breaks."""

also_multi = '''Single triple quotes
work the same way.'''

print(multi)
print("---")
print(also_multi)

# Triple quotes inside functions → docstrings
def greet(name: str) -> str:
    """Return a greeting for `name`.

    This triple-quoted string is the function's docstring,
    accessible via greet.__doc__ or help(greet).
    """
    return f"Hello, {name}!"

print(greet.__doc__[:30])
help(greet)  # would show the docstring

# Implicit concatenation — adjacent string literals are joined at compile time
# (useful for long strings without `+` or `\`)
long = ("This is a very long string that "
        "spans multiple lines via implicit "
        "concatenation.")
print(long)

# Also works with triple quotes
query = ("SELECT * "
         "FROM users "
         "WHERE active = 1")
print(query)  # SELECT * FROM users WHERE active = 1
```

## 3. Escaping and Raw Strings

### Escape Sequences

Inside regular strings, `\` starts an escape:

| Escape | Meaning | Example |
|---|---|---|
| `\\` | Literal backslash | `"a\\b"` → `a\b` |
| `\'` `\"` | Literal quote | `"\"hi\""` → `"hi"` |
| `\n` | Newline (U+000A) | `"a\nb"` → two lines |
| `\r` | Carriage return | `"a\rb"` |
| `\t` | Tab | `"a\tb"` |
| `\b` | Backspace | rarely used |
| `\f` | Form feed | rarely used |
| `\xhh` | Byte via 2 hex digits | `"\x41"` → `A` |
| `\ooo` | Character via 1-3 octal digits | `"\101"` → `A` |
| `\N{name}` | Named Unicode | `"\N{SNOWMAN}"` → `☃` |
| `\uXXXX` | 4-digit Unicode | `"\u03C0"` → `π` |
| `\UXXXXXXXX` | 8-digit Unicode | `"\U0001F600"` → `😀` |
| `\a` | Bell (alert) | rarely used |
| `\v` | Vertical tab | rarely used |

```python
# Escape examples
print("Line 1\nLine 2")          # newline
print("Column1\tColumn2")        # tab
print("Say \"hello\"")           # escaped quotes
print("Path: C:\\Users\\Alice")  # escaped backslash
print("\x41\x42\x43")            # ABC via hex
print("\u03C0 \u03B1 \u03B2")    # π α β via 4-digit Unicode
print("\U0001F600")              # 😀 via 8-digit Unicode
print("\N{GREEK SMALL LETTER PI}")  # π via name

# repr() shows escapes — useful for debugging
s = "hello\nworld"
print(repr(s))   # 'hello\nworld' — shows the \n
print(s)         # hello
                 # world — actual newline

# Invalid escapes — e.g., "\d" is not a valid escape
# In modern Python (3.6+), invalid escapes like "\d" trigger DeprecationWarning
# and will eventually become SyntaxError. Always use raw strings or \\ for regex.
# import warnings
# print("\d")  # DeprecationWarning: invalid escape sequence '\d'
```

### Raw Strings — `r"..."`

Prefix `r` or `R` disables most escapes — backslashes are literal. Essential for regex and Windows paths.

```python
# Regular string — backslashes are escapes
pattern_regular = "\\d+\\.\\d+"    # to match digits.digits, need double escaping
print(pattern_regular)             # \d+\.\d+
print(repr(pattern_regular))       # '\\d+\\.\\d+'

# Raw string — backslashes are literal
pattern_raw = r"\d+\.\d+"          # same pattern, far more readable
print(pattern_raw)                 # \d+\.\d+
print(pattern_raw == pattern_regular)  # True — same final value!

# Raw strings are the standard for regex
import re
text = "Price: 19.99, Discount: 5.00"
prices = re.findall(r"\d+\.\d+", text)
print(prices)  # ['19.99', '5.00']

# Windows paths
path_regular = "C:\\Users\\Alice\\Documents"  # double backslash
path_raw = r"C:\Users\Alice\Documents"        # raw — single backslash is literal
print(path_regular == path_raw)  # True
print(path_raw)

# Raw strings still handle quotes — and the one gotcha:
# A raw string cannot end with a single backslash (it would escape the quote)
# raw_bad = r"C:\"  # SyntaxError!
raw_ok = r"C:\Users\Alice" + "\\"  # workaround — concatenate
print(raw_ok)  # C:\Users\Alice\
# Or just use forward slashes — Python handles them on all platforms
forward = "C:/Users/Alice/Documents"
print(forward)

# Raw strings + triple quotes — for multi-line regex / docs
regex_verbose = r"""
    \d+          # integer part
    \.           # decimal point
    \d+          # fractional part
"""
```

## 4. Unicode — Code Points, `\u` Escapes, and Normalisation

Python `str` stores Unicode code points. Every character — Latin, CJK, emoji — is a code point.

```python
# Code points — ord() and chr()
print(ord("A"))      # 65
print(ord("π"))      # 960
print(ord("😀"))    # 128512
print(chr(65))       # A
print(chr(960))      # π
print(chr(128512))   # 😀

# Unicode escapes in string literals
print("\u03C0")       # π — 4 hex digits (BMP only, U+0000 to U+FFFF)
print("\U0001F600")   # 😀 — 8 hex digits (any code point)
print("\N{GRINNING FACE}")  # 😀 — by name

# The same characters can also just be typed directly (source file is UTF-8)
direct = "π ≈ 3.14 and 😀 is happy"
print(direct)
print(len(direct))   # counts code points — but emoji length can surprise
print(len("😀"))    # 1 — one code point
print(len("café"))   # 4
print(len("café"))   # careful — see normalisation below

# Grapheme clusters vs code points — len() counts code points, not "visible characters"
# The flag emoji 🇺🇸 is TWO code points (regional indicators) but ONE visible glyph
flag = "🇺🇸"
print(len(flag))            # 2 — two code points
print([hex(ord(c)) for c in flag])  # ['0x1f1fa', '0x1f1f8']

# Combining characters — e.g., é can be 1 or 2 code points!
import unicodedata
e_acute_single = "é"          # U+00E9 — single code point
e_acute_combined = "e\u0301"  # e + combining acute accent — two code points
print(e_acute_single == e_acute_combined)  # False — different code point sequences!
print(len(e_acute_single))   # 1
print(len(e_acute_combined)) # 2
print(repr(e_acute_single), repr(e_acute_combined))

# Normalisation — canonicalise before comparing
print(unicodedata.normalize("NFC", e_acute_combined) == unicodedata.normalize("NFC", e_acute_single))  # True
print(unicodedata.normalize("NFD", e_acute_single) == unicodedata.normalize("NFD", e_acute_combined))  # True

# Always normalise user input before comparison if combining characters are possible
def names_equal(a: str, b: str) -> bool:
    return unicodedata.normalize("NFC", a) == unicodedata.normalize("NFC", b)

print(names_equal("café", "café"))    # True
print(names_equal("café", "cafe\u0301"))  # True after NFC

# Case folding — stronger than .lower() for caseless matching
print("straße".lower() == "STRASSE".lower())       # False — ß lowercases to ß
print("straße".casefold() == "STRASSE".casefold()) # True — casefold handles ß → ss
# Use .casefold() for caseless comparisons; .lower() for display.
```

## 5. Encoding vs Decoding — `str` ↔ `bytes`

This is the boundary between text and binary. Getting it wrong produces `UnicodeEncodeError` / `UnicodeDecodeError` / `mojibake`.

```
  str (text, Unicode)  ──encode(encoding)──►  bytes (binary)
  str (text, Unicode)  ◄──decode(encoding)──  bytes (binary)

  Text in your program is ALWAYS str.
  Data on disk / network is ALWAYS bytes until you decode it.
```

```python
# Encoding — str → bytes
text = "café 😀"
encoded = text.encode("utf-8")
print(encoded)        # b'caf\xc3\xa9 \xf0\x9f\x98\x80'
print(type(encoded))  # <class 'bytes'>
print(len(text))      # 6 — code points
print(len(encoded))   # 10 — bytes (é is 2 bytes, 😀 is 4 bytes in UTF-8)

# Decoding — bytes → str
decoded = encoded.decode("utf-8")
print(decoded)        # café 😀
print(decoded == text)  # True — round-trip

# UTF-8 is the default and almost always what you want
# Explicit is better: always pass the encoding name
print(text.encode())  # defaults to utf-8 — same as text.encode("utf-8")

# Common encodings — know when you need them
# utf-8: variable 1-4 bytes, ASCII-compatible, web standard, Python default
# utf-16: 2 or 4 bytes, used by Windows internals, Java
# latin-1 (iso-8859-1): 1 byte, first 256 code points, never fails for byte→str
# ascii: 1 byte, 0-127 only, fails on non-ASCII

# Errors — what happens with unrepresentable characters
try:
    "café".encode("ascii")
except UnicodeEncodeError as e:
    print(f"UnicodeEncodeError: {e}")
    # 'ascii' codec can't encode character '\xe9'

# Error handlers
print("café".encode("ascii", errors="replace"))   # b'caf?' — replace with ?
print("café".encode("ascii", errors="ignore"))    # b'caf' — skip
print("café".encode("ascii", errors="xmlcharrefreplace"))  # b'caf&#233;'
print("café".encode("ascii", errors="backslashreplace"))   # b'caf\\xe9'

# Decoding errors — bytes that aren't valid in the claimed encoding
bad_bytes = b"\xff\xfe"
try:
    bad_bytes.decode("utf-8")
except UnicodeDecodeError as e:
    print(f"UnicodeDecodeError: {e}")

print(bad_bytes.decode("utf-8", errors="replace"))  # �� — replacement characters
print(bad_bytes.decode("latin-1"))  # ÿþ — latin-1 never fails (maps bytes 0-255 directly)

# File I/O — always specify encoding explicitly
# WRONG — relies on locale-dependent default
# open("data.txt").read()

# CORRECT — explicit UTF-8
# with open("data.txt", encoding="utf-8") as f:
#     content = f.read()

# For binary files — no encoding, work with bytes
# with open("image.png", "rb") as f:
#     data: bytes = f.read()
```

## 6. f-Strings — The Modern Workhorse (PEP 498, Python 3.6+)

f-strings (`f"..."`) are the preferred formatting mechanism — fastest, most readable, most powerful.

### Basics — Expressions Inside `{}`

```python
name = "Alice"
age = 30
print(f"Hello, {name}! You are {age} years old.")
# Hello, Alice! You are 30 years old.

# Any expression — not just variable names
print(f"Next year: {age + 1}")              # 31
print(f"Upper: {name.upper()}")             # ALICE
print(f"Sum: {2 + 3}")                      # 5
print(f"Joined: {', '.join(['a', 'b'])}")  # Joined: a, b
print(f"Result: {max(10, 20, 5)}")          # Result: 20

# Method calls, indexing, slicing — all valid
user = {"name": "Bob", "scores": [85, 92, 78]}
print(f"Top score: {max(user['scores'])}")  # 92
print(f"Name: {user['name']!r}")            # 'Bob' — with !r

# Multi-line f-strings
value = 42
message = (
    f"Processing value {value} "
    f"with status {'OK' if value > 0 else 'FAIL'}"
)
print(message)
```

### Conversion Flags — `!s`, `!r`, `!a`

Control how the value is converted to string *before* formatting:

| Flag | Calls | Purpose |
|---|---|---|
| `!s` | `str(value)` | Human-readable (default) |
| `!r` | `repr(value)` | Debug representation (with quotes/escapes) |
| `!a` | `ascii(value)` | ASCII-only repr (non-ASCII escaped) |

```python
value = "hello\nworld"
print(f"str:   {value!s}")  # hello
                             # world
print(f"repr:  {value!r}")  # 'hello\nworld'
print(f"ascii: {value!a}")  # 'hello\nworld'

# With Unicode
text = "café"
print(f"s: {text!s}")  # café
print(f"r: {text!r}")  # 'café'
print(f"a: {text!a}")  # 'caf\xe9' — non-ASCII escaped

# Common use — logging with !r to see exact values
user_input = "  hello  "
print(f"Got input: {user_input!r} (len={len(user_input)})")
# Got input: '  hello  ' (len=9) — visible whitespace
```

### Format Specifiers — `:` Mini-Language

After the expression (and optional `!` conversion), `:` introduces a format spec. Full syntax: `[[fill]align][sign][#][0][width][grouping][.precision][type]`

```python
# Numeric formatting
n = 42
pi = 3.14159265
big = 1_000_000

print(f"{n:05d}")       # 00042 — zero-padded width 5
print(f"{n:>10}")       #         42 — right-aligned width 10
print(f"{n:<10}end")    # 42        end — left-aligned
print(f"{n:^10}end")    #     42    end — centred
print(f"{big:,}")       # 1,000,000 — comma grouping
print(f"{big:_}")       # 1_000_000 — underscore grouping
print(f"{pi:.2f}")      # 3.14 — 2 decimal places
print(f"{pi:.4e}")      # 3.1416e+00 — scientific
print(f"{pi:.2%}")      # 314.16% — percentage (×100 + %)
print(f"{42:#x}")       # 0x2a — hex with prefix
print(f"{42:#b}")       # 0b101010 — binary with prefix
print(f"{42:#o}")       # 0o52 — octal with prefix
print(f"{0.5:.0%}")     # 50% — percentage, no decimals

# String formatting
s = "hello"
print(f"{s:>10}")       #      hello
print(f"{s:*^15}")      # *****hello***** — fill with *
print(f"{s:.3}")        # hel — truncated to 3 chars

# Date/time formatting (via __format__)
from datetime import datetime
now = datetime(2024, 3, 15, 14, 30, 0)
print(f"{now:%Y-%m-%d %H:%M}")  # 2024-03-15 14:30
print(f"{now:%B %d, %Y}")       # March 15, 2024

# Combining conversion and format spec
value = 3.14159
print(f"{value!s:.2f}")  # 3.14 — str() then format as float

# Dynamic format specs — nested {}
width = 10
precision = 3
print(f"{pi:{width}.{precision}f}")  #      3.142 — width/precision from variables
```

### `=` Debug Specifier (Python 3.8+)

Append `=` to print the expression *and* its value — invaluable for debugging.

```python
x = 42
y = 3.14
name = "Alice"

print(f"{x=}")              # x=42
print(f"{x=}, {y=}")        # x=42, y=3.14
print(f"{x + y=}")          # x + y=45.14
print(f"{name.upper()=}")   # name.upper()='ALICE'

# With format spec
print(f"{y=:.2f}")          # y=3.14

# With !r
print(f"{name=!r}")         # name='Alice'

# Before 3.8 you had to write: print(f"x={x!r}") — now just f"{x=}"
```

### Escaping Braces and Nesting

```python
# Literal braces — double them
print(f"{{hello}}")         # {hello}
print(f"{{{10 + 5}}}")     # {15} — outer {{ and }} are literal, inner {10+5} is expr
n = 42
print(f"{{n}} = {n}")      # {n} = 42

# Quotes inside f-string expressions — must differ from outer quotes or be escaped
name = "Alice"
print(f'He said "hi {name}"')   # He said "hi Alice"
print(f"Value: {'hello ' + name}")  # Value: hello Alice

# Backslashes in expressions — NOT allowed directly (until Python 3.12)
# f"{\n}"  # SyntaxError in <3.12
# Workaround for older versions — assign to variable first
newline = "\n"
# Or use chr(10), etc.

# Python 3.12+ relaxes this — multi-line expressions and backslashes in {} now allowed
# f"{'a\nb'}"  # valid in 3.12+
```

## 7. `.format()` and `%` — Older Formatting

### `str.format()` — Positional, Keyword, Attribute Access

```python
# Positional
print("{} + {} = {}".format(1, 2, 3))        # 1 + 2 = 3
print("{0} {0} {1}".format("hello", "world")) # hello hello world
print("{1} {0}".format("world", "hello"))     # hello world

# Keyword
print("{name} is {age}".format(name="Alice", age=30))
print("{greeting}, {name}!".format(greeting="Hello", name="Bob"))

# Attribute and item access
user = {"name": "Charlie"}
print("Name: {0[name]}".format(user))         # Name: Charlie

class Point:
    x = 10
    y = 20

print("({p.x}, {p.y})".format(p=Point()))     # (10, 20)

# Format specs — same mini-language as f-strings
print("{:.2f}".format(3.14159))               # 3.14
print("{:>10}".format("hello"))               #      hello
print("{:,}".format(1000000))                 # 1,000,000

# When to still use .format():
# 1. Template strings stored separately (e.g., i18n, config)
template = "Hello, {name}! You have {count} messages."
print(template.format(name="Alice", count=5))

# 2. Dynamic template from user/config — f-strings require literal
def render(template: str, **kwargs) -> str:
    return template.format(**kwargs)

print(render("Hi {name}", name="Bob"))        # Hi Bob
```

### `%` Formatting — Legacy (Still Seen in Logging)

```python
# Old printf-style — still used in logging for lazy evaluation
print("Hello, %s! You are %d years old." % ("Alice", 30))
print("Value: %.2f" % 3.14159)               # Value: 3.14
print("Hex: %x, Octal: %o" % (255, 8))       # Hex: ff, Octal: 10

# Mapping variant
print("Hello, %(name)s!" % {"name": "Bob"})

# Why it persists — logging uses % for deferred formatting:
import logging
# logging.debug("Value: %s", expensive_function())  # only formats if level enabled
# With f-strings, the string is always formatted even if the log is filtered out.

# Prefer f-strings for new code; recognise % when reading older codebases.
```

## 8. Essential String Methods

All methods return new strings — the original is never mutated.

### Case Conversion

```python
s = "Hello World"
print(s.lower())       # hello world
print(s.upper())       # HELLO WORLD
print(s.capitalize())  # Hello world — first char upper, rest lower
print(s.title())       # Hello World — each word capitalised (naïve — see below)
print(s.swapcase())    # hELLO wORLD
print(s.casefold())    # hello world — aggressive lowercasing for caseless matching

# title() pitfall — doesn't handle apostrophes well
print("they're bill's friends".title())  # They'Re Bill'S Friends — wrong!
# For proper titlecasing, use a library or manual logic.

# Case checks
print("hello".islower())   # True
print("HELLO".isupper())   # True
print("Hello World".istitle())  # True
```

### Trimming and Stripping

```python
s = "  hello world  "
print(repr(s.strip()))   # 'hello world' — both ends
print(repr(s.lstrip()))  # 'hello world  ' — left only
print(repr(s.rstrip()))  # '  hello world' — right only

# Strip specific characters (not a substring — a SET of characters!)
print("www.example.com".strip("w."))  # example.com — strips w and . from both ends
print("www.example.com".strip("cmow."))  # example — strips any of c,m,o,w,. !
print("abccba".strip("ab"))  # cc — strips a and b characters

# Common mistake — strip("ab") does NOT strip the substring "ab"
print("abhelloab".strip("ab"))  # hello — happens to work
print("bahelloab".strip("ab"))  # hello — strips b and a individually
# To strip a prefix/suffix substring, use removesuffix/removeprefix (3.9+):
print("hello_world.py".removesuffix(".py"))  # hello_world
print("test_hello".removeprefix("test_"))    # hello
print("hello.py".removesuffix(".txt"))       # hello.py — no change if suffix absent
```

### Splitting and Joining

```python
# split — str → list[str]
text = "apple,banana,cherry"
print(text.split(","))       # ['apple', 'banana', 'cherry']
print("a b  c".split())      # ['a', 'b', 'c'] — no args: splits on any whitespace, strips empties
print("a b  c".split(" "))   # ['a', 'b', '', 'c'] — explicit " " preserves empties!
print("a,b,c,".split(","))   # ['a', 'b', 'c', ''] — trailing delimiter → trailing ""
print("".split(","))         # [''] — splitting empty string gives [''], not []!
print("".split())            # [] — but split() with no args gives [] for empty string

# rsplit — split from the right (useful with maxsplit)
print("a,b,c,d".split(",", maxsplit=2))   # ['a', 'b', 'c,d']
print("a,b,c,d".rsplit(",", maxsplit=2))  # ['a,b', 'c', 'd']

# splitlines — handles \n, \r\n, \r, and other line boundaries
print("a\nb\r\nc\rd".splitlines())  # ['a', 'b', 'c', 'd']

# partition / rpartition — split into 3 parts around first/last occurrence
print("hello world".partition(" "))   # ('hello', ' ', 'world')
print("hello world".partition("X"))   # ('hello world', '', '') — separator not found
print("a/b/c".rpartition("/"))        # ('a/b', '/', 'c')

# join — list[str] → str (called on the SEPARATOR)
words = ["apple", "banana", "cherry"]
print(", ".join(words))      # apple, banana, cherry
print("".join(words))        # applebananacherry
print(" | ".join(words))     # apple | banana | cherry
print(", ".join([]))         # '' — joining empty list gives empty string

# join requires ALL elements to be str
try:
    print(", ".join(["a", 42]))  # TypeError
except TypeError as e:
    print(f"TypeError: {e}")
# Fix — map str over non-string elements
print(", ".join(map(str, ["a", 42, 3.14])))  # a, 42, 3.14
print(", ".join(str(x) for x in ["a", 42, 3.14]))  # same

# Efficient string building — join is O(n), repeated += is O(n²)
# BAD for large n:
# result = ""
# for word in many_words:
#     result += word  # creates new string each iteration

# GOOD:
# result = "".join(many_words)  # single allocation
```

### Searching and Replacing

```python
s = "hello world, hello Python"

# Finding
print(s.find("hello"))     # 0 — index of first occurrence, -1 if not found
print(s.rfind("hello"))    # 13 — index of last occurrence
print(s.find("xyz"))       # -1 — not found (no exception)
print(s.index("hello"))    # 0 — like find but raises ValueError if not found
try:
    s.index("xyz")
except ValueError as e:
    print(f"ValueError: {e}")

print(s.count("hello"))    # 2
print(s.count("l"))        # 5

# Membership
print("world" in s)        # True
print("xyz" not in s)      # True

# Startswith / endswith — accept tuples for multiple checks (very useful)
print(s.startswith("hello"))              # True
print(s.endswith("Python"))               # True
print(s.startswith(("hello", "hi")))      # True — any of these prefixes
print(s.endswith((".py", ".txt", "Python")))  # True
# Optional start/end positions:
print(s.startswith("world", 6))           # True — check at offset 6

# Replace
print(s.replace("hello", "hi"))           # hi world, hi Python
print(s.replace("hello", "hi", 1))        # hi world, hello Python — count=1
print(s.replace("l", "L"))               # heLLo worLd, heLLo Python

# Replace is NOT regex — for patterns, use re.sub
import re
print(re.sub(r"hello", "hi", s, count=1))  # hi world, hello Python
print(re.sub(r"\s+", "_", "a  b\tc\nd"))  # a_b_c_d — regex replace
```

### Validation and Classification

```python
# Character class checks — all return bool, all require non-empty string
print("hello".isalpha())    # True — only letters
print("hello123".isalpha()) # False — contains digits
print("123".isdigit())      # True — only digits (also isnumeric, isdecimal — see below)
print("123".isalnum())      # True — letters and digits only
print("   ".isspace())      # True — only whitespace
print("hello world".isspace())  # False
print("".isalpha())         # False — empty string is False for all is* checks!

# isdigit vs isnumeric vs isdecimal — subtle Unicode differences
print("42".isdigit())       # True
print("42".isdecimal())     # True
print("42".isnumeric())     # True
print("½".isdigit())        # False — vulgar fraction is not a digit
print("½".isnumeric())      # True — but it IS numeric
print("²".isdigit())        # True — superscript IS a digit
print("²".isdecimal())      # False — but NOT decimal
# For most validation, isdigit() is what you want. Use isnumeric() only if you
# need to accept fractions, superscripts, etc.

# Encoding-safe alpha check for ASCII-only contexts
print("hello".isascii())    # True — all chars are ASCII (3.7+)
print("café".isascii())     # False — é is not ASCII
```

## 9. Immutability Implications

Because `str` is immutable, every transformation allocates a new string. This has performance and correctness consequences.

```python
# Correctness — functions cannot mutate your string
def shout(text: str) -> str:
    text = text.upper() + "!!!"  # new string, local rebinding
    return text

original = "hello"
result = shout(original)
print(original)  # hello — unchanged
print(result)    # HELLO!!!

# Performance — repeated concatenation in a loop
# Each `+=` creates a new string and copies all previous content — O(n²) total.

# BAD — quadratic for large n
def build_bad(words: list[str]) -> str:
    result = ""
    for w in words:
        result += w + " "  # new string each iteration
    return result

# GOOD — linear, single allocation
def build_good(words: list[str]) -> str:
    return " ".join(words)

# For REALLY large strings or streaming, use io.StringIO
import io

def build_streaming(words: list[str]) -> str:
    buf = io.StringIO()
    for w in words:
        buf.write(w)
        buf.write(" ")
    return buf.getvalue()

# Hashability — immutable strings can be dict keys and set members
d = {"hello": 1, "world": 2}
s = {"a", "b", "c"}
print("hello" in d)  # True
print("a" in s)      # True
# (Mutable types like list/bytearray cannot be hashed — see Lesson 01.8)
```

## 10. String Interning

CPython interns some strings — reusing the same object for equal values — as a memory and speed optimisation. Like small-int caching, this is an implementation detail.

```python
import sys

# Implicit interning — identifiers and short strings that look like identifiers
a = "hello"
b = "hello"
print(a is b)  # True — likely interned (identifier-like, short)

# Longer strings or strings with special characters — usually NOT interned
a = "hello world! this is a longer string with spaces and punctuation!!!"
b = "hello world! this is a longer string with spaces and punctuation!!!"
print(a is b)  # Likely False — not interned (but don't rely on it!)
print(a == b)  # True — always use == for value comparison

# Dynamically constructed strings — NOT interned even if short
a = "hello"
b = "hel" + "lo"  # constant folding may intern this at compile time
print(a is b)  # May be True — compiler optimisation

a = "hello"
b = "".join(["hel", "lo"])  # runtime construction — NOT interned
print(a is b)  # False
print(a == b)  # True

# Explicit interning — for deduplication when you have many duplicate strings
# (e.g., parsing CSV/JSON with repeated keys)
a = sys.intern("hello_" + str(123))  # dynamically built
b = sys.intern("hello_" + str(123))
print(a is b)  # True — explicitly interned, same object

# When interning helps — imagine parsing a CSV with 1M rows, same column names
# Without interning: 1M separate "username" string objects
# With interning: 1 shared "username" object → less memory, faster `is` checks
# Use sys.intern() when you know strings will be heavily duplicated.

# NEVER use `is` for string comparison (except interned sentinels you control)
# ALWAYS use `==`
```

## 11. Realistic Example — Text Processing Pipeline

```python
import re
import unicodedata
from collections import Counter

def process_text(raw: str) -> dict:
    """
    Clean, normalise, and analyse a block of text.
    Demonstrates encoding, normalisation, f-strings, methods, and interning.
    """
    # 1. Normalise Unicode — ensure composed form for consistent comparison
    text = unicodedata.normalize("NFC", raw)

    # 2. Strip and check emptiness via truthiness
    text = text.strip()
    if not text:
        return {"error": "Empty input after stripping"}

    # 3. Case-fold for analysis (preserve original for display)
    lowered = text.casefold()

    # 4. Tokenise — split on non-word characters via regex
    #    (str.split() alone can't handle punctuation properly)
    words = re.findall(r"\b\w+\b", lowered)
    #    re.findall with \w respects Unicode word characters

    # 5. Count frequencies
    freq = Counter(words)

    # 6. Build report with f-strings
    total_words = len(words)
    unique_words = len(freq)
    most_common = freq.most_common(3)

    # Format with alignment and grouping
    report_lines = [
        f"Text:     {text[:50]!r}{'...' if len(text) > 50 else ''}",
        f"Length:   {len(text):,} characters, {total_words:,} words",
        f"Unique:   {unique_words:,} distinct words",
        f"Top 3:    {', '.join(f'{w}({c})' for w, c in most_common)}",
    ]

    # 7. Demonstrate encode/decode round-trip
    encoded = text.encode("utf-8")
    assert encoded.decode("utf-8") == text  # round-trip check

    return {
        "original": text,
        "words": words,
        "frequencies": dict(freq),
        "report": "\n".join(report_lines),
        "utf8_bytes": len(encoded),
        "code_points": len(text),
    }

# --- Demo ---
samples = [
    "  Hello, World! Hello Python. café → CAFÉ (café)  ",
    "The quick brown fox jumps over the lazy dog. The dog was lazy!",
    "  ",  # empty after strip
    "straße and STRASSE are the same when casefolded: Straße",
]

for sample in samples:
    result = process_text(sample)
    print("=" * 60)
    if "error" in result:
        print(f"Input: {sample!r} → {result['error']}")
    else:
        print(result["report"])
        print(f"Bytes (UTF-8): {result['utf8_bytes']}, Code points: {result['code_points']}")

# --- Encoding edge case: file I/O ---
# Always specify encoding when writing text:
# with open("/tmp/output.txt", "w", encoding="utf-8") as f:
#     f.write(result["report"])
#
# Reading unknown encoding — try utf-8 first, fall back to latin-1:
# def read_text_safely(path: str) -> str:
#     try:
#         with open(path, encoding="utf-8") as f:
#             return f.read()
#     except UnicodeDecodeError:
#         with open(path, encoding="latin-1") as f:
#             return f.read()
```

## 12. Common Mistakes and Pythonic Idioms

| Mistake | Why It Fails | Correct Approach |
|---|---|---|
| `s[0] = "H"` | `str` is immutable | `s = "H" + s[1:]` or `s.capitalize()` |
| `"hello".strip("he")` expecting to strip substring `"he"` | `strip` takes a *set* of chars | `"hello".removeprefix("he")` (3.9+) |
| `", ".join(["a", 42])` | Non-str elements | `", ".join(map(str, items))` |
| `result += s` in a loop (large n) | O(n²) copying | `"".join(pieces)` or `io.StringIO` |
| `if s is "hello":` | Identity vs equality | `if s == "hello":` |
| `"café".encode("ascii")` | Non-ASCII char | `"café".encode("utf-8")` or handle errors |
| `open("file.txt").read()` | Locale-dependent encoding | `open("file.txt", encoding="utf-8").read()` |
| `s.lower() == t.lower()` for caseless compare | Fails for `ß`, etc. | `s.casefold() == t.casefold()` |
| `f"{\n}"` in Python <3.12 | SyntaxError | Assign `nl = "\n"` first, then `f"{nl}"` |
| Comparing `"café"` vs `"cafe\u0301"` | Different code point sequences | `unicodedata.normalize("NFC", s)` first |

**Pythonic idioms:**

```python
# Building strings
words = ["hello", "world"]
sentence = " ".join(words)              # not repeated +=

# Checking emptiness — truthiness, not len
if not s:                               # not `if len(s) == 0:` or `if s == "":`
    print("empty")

# Prefix/suffix checks — tuple for multiple
if filename.endswith((".py", ".pyi")):  # not `filename[-3:] == ".py"`
    print("Python file")

# Removing prefix/suffix — removeprefix/removesuffix (3.9+)
clean = filename.removesuffix(".py")    # not `filename[:-3] if ... else`

# Caseless comparison
if a.casefold() == b.casefold():        # not `a.lower() == b.lower()`

# Debug printing — !r and = specifier
print(f"{value!r}")                     # shows quotes, escapes
print(f"{value=}")                      # Python 3.8+ debug

# Raw strings for regex
pattern = re.compile(r"\d{4}-\d{2}-\d{2}")  # not "\\d{4}-\\d{2}-\\d{2}"
```

## 13. Summary

- **`str` is an immutable sequence of Unicode code points** — no separate `char` type; indexing returns a length-1 `str`; all "mutations" create new strings.
- **Quoting:** `'...'` and `"..."` are identical; `"""..."""` for multi-line/docstrings; implicit concatenation for long literals.
- **Escaping:** `\n`/`\t`/`\x..`/`\u....`/`\U........`/`\N{name}`; use `r"..."` for regex/paths where backslashes are literal; raw strings cannot end with a single `\`.
- **Unicode:** `ord()`/`chr()`, `\u`/`\U` escapes, `unicodedata.normalize()` for canonical comparison, `.casefold()` for caseless matching.
- **Encoding:** `str.encode("utf-8") → bytes`, `bytes.decode("utf-8") → str`; always specify encoding in `open()`; UTF-8 is the default and almost always correct.
- **f-strings:** `f"{expr!r:.2f}"` with `!s`/`!r`/`!a`, full format mini-language, `=` debug specifier; prefer f-strings for new code, `.format()` for templates, `%` only for logging.
- **Methods:** All return new strings; `strip` takes a character *set*; `split()` vs `split(" ")` differ on whitespace handling; `join` requires all `str` elements; `startswith`/`endswith` accept tuples; `replace` is not regex.
- **Performance:** Use `"".join()` or `io.StringIO` for building large strings, not `+=` in a loop.
- **Interning:** Short identifier-like strings may be interned — never use `is` for string comparison; use `sys.intern()` for deduplication of heavily repeated strings.

> **Key takeaway:** Think of `str` as *text* (Unicode, immutable, human-facing) and `bytes` as *data* (binary, for I/O). Keep them separate, encode/decode explicitly at the boundaries, and use f-strings + the rich method set to manipulate text without ever trying to mutate it in place.
