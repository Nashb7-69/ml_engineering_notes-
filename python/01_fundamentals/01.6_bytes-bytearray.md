# 01.6 Bytes and Bytearray

> **Mental model:** `str` is for *text* (Unicode code points, human-readable). `bytes` and `bytearray` are for *binary data* (sequences of 0–255 integers, machine-readable). The boundary between them is `encode`/`decode` — and crossing it explicitly is one of Python's core design decisions.

If you come from languages where strings and byte arrays are interchangeable (C, older Python 2), Python 3's strict separation can feel pedantic. It is deliberate: it prevents an entire class of encoding bugs by making you state your assumptions at every boundary.

---

## 1. `bytes` — Immutable Sequences of Bytes

A `bytes` object is an immutable sequence of integers in the range 0–255. Each element is a *byte* — not a character, not a code point.

```python
# Creating bytes
b1 = b"hello"              # bytes literal — b prefix, ASCII only
print(type(b1))            # <class 'bytes'>
print(b1)                  # b'hello'
print(len(b1))             # 5 — number of bytes
print(b1[0])               # 104 — int, NOT b'h'! Indexing bytes gives int.
print(type(b1[0]))         # <class 'int'>

# Compare with str — str[0] gives str, bytes[0] gives int
s = "hello"
print(s[0], type(s[0]))    # h <class 'str'>
print(b1[0], type(b1[0]))  # 104 <class 'int'>

# Slicing bytes gives bytes (consistent with str)
print(b1[0:2])             # b'he'
print(type(b1[0:2]))       # <class 'bytes'>

# Iterating bytes gives ints
for byte in b"ABC":
    print(byte, hex(byte))
# 65 0x41
# 66 0x42
# 67 0x43

# bytes is immutable — like str
# b1[0] = 72  # TypeError: 'bytes' object does not support item assignment
```

### Bytes Literals — What's Allowed

Bytes literals (`b"..."` or `b'...'`) can only contain ASCII characters. Non-ASCII must be escaped.

```python
# Valid bytes literals — all ASCII
a = b"hello world"
b = b'hello world'         # single or double quotes — same as str
c = b"""hello
world"""                    # triple-quoted bytes (rare)
d = b"line1\nline2\ttab"   # escapes work: \n, \t, \x, etc.

# Hex escapes for non-ASCII bytes
e = b"\x48\x65\x6c\x6c\x6f"  # b'hello' via hex
print(e)                     # b'hello'
print(e == b"hello")         # True — same bytes

# Raw bytes — r prefix combines with b (order doesn't matter)
raw = rb"\d+\.\d+"          # raw bytes for regex on binary data
print(raw)                   # b'\\d+\\.\\d+'

# INVALID — non-ASCII in bytes literal
# bad = b"café"  # SyntaxError: bytes can only contain ASCII literal characters
# Must escape non-ASCII:
ok = "café".encode("utf-8")  # b'caf\xc3\xa9' — correct way
print(ok)
print(list(ok))  # [99, 97, 102, 195, 169] — the 5 bytes of "café" in UTF-8

# From integers — bytes(n) creates n zero bytes
print(bytes(5))              # b'\x00\x00\x00\x00\x00'
# From iterable of ints
print(bytes([72, 101, 108, 108, 111]))  # b'Hello'
# From existing bytes
print(bytes(b"hello"))       # b'hello' — copy
```

### How `bytes` Displays

Python displays `bytes` by showing ASCII-printable bytes as characters and non-printable as `\xNN`:

```python
print(b"hello")              # b'hello' — printable ASCII shown as chars
print(b"\x00\x01\x02")       # b'\x00\x01\x02' — non-printable as hex
print(b"hello\xff\xfe")      # b'hello\xff\xfe' — mix
print(bytes([72, 101, 108, 108, 111]))  # b'Hello' — same

# repr vs actual content — don't confuse display with value
data = bytes([0x48, 0x65, 0x6c, 0x6c, 0x6f])
print(repr(data))            # "b'Hello'"
print(list(data))            # [72, 101, 108, 108, 111] — the ints
```

## 2. `str` vs `bytes` — The Critical Distinction

| Aspect | `str` | `bytes` |
|---|---|---|
| **Contains** | Unicode code points | Integers 0–255 |
| **Element type** | `str` (length-1) on indexing | `int` on indexing |
| **Mutable?** | No | No (`bytearray` is the mutable variant) |
| **Literal** | `"hello"` | `b"hello"` |
| **Length of `"café"`** | `4` (code points) | `5` in UTF-8 (`b"caf\xc3\xa9"`) |
| **Used for** | Text, human-readable | Binary data, I/O, protocols |
| **Can encode?** | `str.encode() → bytes` | — |
| **Can decode?** | — | `bytes.decode() → str` |

```python
# The fundamental rule — str and bytes NEVER implicitly convert
text: str = "hello"
data: bytes = b"hello"

print(text == data)  # False — different types, never equal (no TypeError, just False)
# But operations that MIX them raise TypeError:
try:
    print(text + data)
except TypeError as e:
    print(f"TypeError: {e}")  # can only concatenate str (not "bytes") to str

try:
    print(b"hello " + "world")
except TypeError as e:
    print(f"TypeError: {e}")  # can't concat str to bytes

# You must explicitly cross the boundary:
print(text.encode("utf-8") + data)        # b'hellohello' — both bytes
print(text + data.decode("utf-8"))        # hellohello — both str

# In Python 2, str WAS bytes and this confusion caused endless bugs.
# Python 3's strict separation forces you to be explicit — embrace it.
```

### When You Encounter Each

```python
# You get `str` from:
# - String literals: "hello"
# - Text file reads: open("file.txt", encoding="utf-8").read()
# - User input: input()
# - Decoded bytes: data.decode("utf-8")

# You get `bytes` from:
# - Bytes literals: b"hello"
# - Binary file reads: open("file.bin", "rb").read()
# - Network I/O: socket.recv(1024)
# - Encoded strings: "hello".encode("utf-8")
# - Many stdlib functions: hashlib, struct, pickle (in binary mode)

# Practical — reading files
# Text mode (default) — returns str, handles encoding
# with open("data.txt", encoding="utf-8") as f:
#     text: str = f.read()

# Binary mode ("rb") — returns bytes, no encoding
# with open("data.txt", "rb") as f:
#     data: bytes = f.read()

# Network — always bytes until you decode
# import socket
# sock = socket.socket()
# data: bytes = sock.recv(1024)
# text: str = data.decode("utf-8")
```

## 3. Encoding and Decoding — Crossing the Boundary

This was introduced in Lesson 01.5; here we go deeper into the `bytes` side.

```python
# === Encoding: str → bytes ===

text = "Hello, café! 😀"

# UTF-8 — variable 1-4 bytes per code point, ASCII-compatible, web standard
utf8 = text.encode("utf-8")
print(utf8)         # b'Hello, caf\xc3\xa9! \xf0\x9f\x98\x80'
print(len(utf8))    # 18 bytes (vs 14 code points in the str)
print(list(utf8))   # [72, 101, 108, 108, 111, 44, 32, 99, 97, 102, 195, 169, 33, 32, 240, 159, 152, 128]

# UTF-16 — 2 or 4 bytes per code point, with BOM
utf16 = text.encode("utf-16")
print(utf16[:20])   # b'\xff\xfeH\x00e\x00l\x00l\x00o\x00' — starts with BOM
print(len(utf16))   # 30 bytes

# Latin-1 — 1 byte per code point, only 0-255
print("café".encode("latin-1"))  # b'caf\xe9' — é is 0xe9 in latin-1
# "😀".encode("latin-1")  # UnicodeEncodeError — 😀 not in latin-1

# ASCII — 1 byte, only 0-127
print("hello".encode("ascii"))  # b'hello'
# "café".encode("ascii")  # UnicodeEncodeError

# === Decoding: bytes → str ===

# UTF-8 decode
print(utf8.decode("utf-8"))   # Hello, café! 😀
print(utf8.decode("utf-8") == text)  # True — round-trip

# Wrong encoding → mojibake or error
mojibake = "café".encode("utf-8").decode("latin-1")
print(mojibake)  # cafÃ© — latin-1 misinterprets the two UTF-8 bytes of é

# Decoding non-UTF-8 bytes as UTF-8 → error
bad = b"\xff\xfe\xfd"
try:
    bad.decode("utf-8")
except UnicodeDecodeError as e:
    print(f"UnicodeDecodeError: {e}")

# Error handlers
print(bad.decode("utf-8", errors="replace"))   # ��� — replacement chars
print(bad.decode("utf-8", errors="ignore"))    # "" — skipped
print(bad.decode("utf-8", errors="backslashreplace"))  # \xff\xfe\xfd
print(bad.decode("latin-1"))  # ÿþý — latin-1 maps every byte, never fails

# The `errors` parameter works for both encode and decode:
print("café".encode("ascii", errors="replace"))  # b'caf?'
print("café".encode("ascii", errors="xmlcharrefreplace"))  # b'caf&#233;'
print("café".encode("ascii", errors="namereplace"))  # b'caf\\N{LATIN SMALL LETTER E WITH ACUTE}'
```

### Hex and Other Representations

```python
# Hex encoding — bytes ↔ hex string (useful for debugging, crypto)
data = b"\xde\xad\xbe\xef"
print(data.hex())              # deadbeef
print(data.hex(" "))           # de ad be ef — separator (3.8+)
print(data.hex(":", 2))        # dead:beef — separator every 2 bytes

# Hex string → bytes
print(bytes.fromhex("deadbeef"))     # b'\xde\xad\xbe\xef'
print(bytes.fromhex("de ad be ef"))  # same — spaces ignored

# Base64 — bytes ↔ ASCII string (for embedding binary in text protocols)
import base64
original = b"Hello, world!"
encoded_b64 = base64.b64encode(original)
print(encoded_b64)             # b'SGVsbG8sIHdvcmxkIQ=='
print(base64.b64decode(encoded_b64))  # b'Hello, world!'

# As text string:
print(base64.b64encode(original).decode("ascii"))  # SGVsbG8sIHdvcmxkIQ==

# Struct — packing binary data (network protocols, file formats)
import struct
# Pack ints as big-endian binary
packed = struct.pack(">HI", 1000, 99999)  # > = big-endian, H = uint16, I = uint32
print(packed)                  # b'\x03\xe8\x00\x01\x86\x9f'
print(packed.hex(" "))         # 03 e8 00 01 86 9f
unpacked = struct.unpack(">HI", packed)
print(unpacked)                # (1000, 99999)
```

## 4. `bytearray` — The Mutable Variant

`bytearray` is to `bytes` as `list` is to `tuple` — same content, but mutable.

```python
# Creating a bytearray
ba = bytearray(b"hello")
print(type(ba))    # <class 'bytearray'>
print(ba)          # bytearray(b'hello')
print(len(ba))     # 5
print(ba[0])       # 104 — int, like bytes

# Key difference — MUTABLE
ba[0] = 72         # change first byte to 'H' (72)
print(ba)          # bytearray(b'Hello')

ba[1:4] = b"ELLO"  # slice assignment
print(ba)          # bytearray(b'HELLOo')

ba.append(33)      # append single byte (int 0-255)
print(ba)          # bytearray(b'HELLOo!')

ba.extend(b" World")
print(ba)          # bytearray(b'HELLOo! World')

del ba[5]          # delete a byte
print(ba)          # bytearray(b'HELLO! World')

ba.insert(0, 62)   # insert byte at position
print(ba)          # bytearray(b'>HELLO! World')

# Construct from various sources
print(bytearray(5))                    # bytearray(b'\x00\x00\x00\x00\x00') — 5 zero bytes
print(bytearray([72, 101, 108, 108, 111]))  # bytearray(b'Hello')
print(bytearray("café", "utf-8"))      # bytearray(b'caf\xc3\xa9') — from str + encoding

# bytearray methods — mostly same as bytes, but some mutate in place
ba2 = bytearray(b"hello world")
ba2[0:5] = b"HELLO"  # mutable slice assignment — bytes cannot do this
print(ba2)            # bytearray(b'HELLO world')

# bytes vs bytearray method comparison
data_bytes = b"hello world"
data_ba = bytearray(b"hello world")

# Both support: find, count, split, replace, startswith, etc.
print(data_bytes.split(b" "))    # [b'hello', b'world']
print(data_ba.split(b" "))       # [bytearray(b'hello'), bytearray(b'world')]

# But bytearray additionally supports: append, extend, insert, pop, remove, clear
data_ba.append(33)
print(data_ba)  # bytearray(b'hello world!')
# data_bytes.append(33)  # AttributeError — bytes has no append

# Converting between them
ba = bytearray(b"hello")
b = bytes(ba)           # bytearray → bytes (copy)
ba2 = bytearray(b)      # bytes → bytearray (copy)
print(b, ba2)

# Hashability — bytes is hashable (can be dict key), bytearray is NOT
d = {b"key": "value"}   # OK
print(d[b"key"])        # value
# d2 = {bytearray(b"key"): "value"}  # TypeError: unhashable type: 'bytearray'
# (Same as list vs tuple — mutable types cannot be hashed. See Lesson 01.8.)
```

### When to Use Each

| Type | Use When |
|---|---|
| `bytes` | Binary data you won't modify — file contents, network packets, hash digests, dict keys |
| `bytearray` | Binary data you build or mutate incrementally — assembling packets, in-place editing, buffers |

```python
# Example — building binary data efficiently
# BAD — bytes concatenation creates new object each time (like str +=)
result = b""
for chunk in [b"hello", b" ", b"world"]:
    result += chunk  # new bytes each iteration — O(n²)

# GOOD — bytearray for incremental building
buf = bytearray()
for chunk in [b"hello", b" ", b"world"]:
    buf.extend(chunk)  # mutates in place — O(n)
result = bytes(buf)    # finalise as immutable bytes if needed
print(result)          # b'hello world'

# ALSO GOOD — b"".join for known chunks
result2 = b"".join([b"hello", b" ", b"world"])
print(result2)         # b'hello world' — also O(n), often fastest

# For I/O, bytearray can be used as a writable buffer
import io
buf = io.BytesIO()
buf.write(b"hello ")
buf.write(b"world")
print(buf.getvalue())  # b'hello world'
```

## 5. `memoryview` — Zero-Copy Access to Binary Data

`memoryview` provides a *view* into the memory of another binary object without copying. Critical for performance with large binary data (numpy arrays, network buffers, file mappings).

```python
# Basic — wrap bytes or bytearray
data = bytearray(b"hello world")
view = memoryview(data)
print(type(view))      # <class 'memoryview'>
print(view[0])         # 104 — int
print(view[0:5])       # <memory at ...> — still a view, no copy
print(bytes(view[0:5]))# b'hello' — materialise as bytes

# The power — slicing a memoryview does NOT copy data
large = bytearray(b"x" * 1_000_000)
view = memoryview(large)
slice_view = view[100:200]  # no copy — just a window into the same memory
print(len(slice_view))      # 100

# Modifying through the view modifies the original (if writable)
data = bytearray(b"hello")
view = memoryview(data)
view[0] = 72  # modify through view
print(data)   # bytearray(b'Hello') — original changed!

# Views of bytes are read-only (bytes is immutable)
ro_data = b"hello"
ro_view = memoryview(ro_data)
# ro_view[0] = 72  # TypeError: cannot modify read-only memory

# Casting — reinterpret bytes as different types
import struct
# View 4 bytes as a 32-bit integer without copying
buf = bytearray(struct.pack(">I", 0xDEADBEEF))
view = memoryview(buf)
# Cast to unsigned int (native) — reinterpret the bytes
# Note: cast format follows struct module codes
int_view = view.cast("I")  # platform-dependent size/endianness!
print(int_view[0])         # reinterpreted integer (value depends on endianness)

# Safer — use struct for explicit endianness:
print(struct.unpack(">I", buf)[0])  # 3735928559 — 0xDEADBEEF, explicit big-endian

# nbytes, itemsize, shape — for structured views
data = bytearray(b"\x01\x02\x03\x04\x05\x06")
view = memoryview(data)
print(view.nbytes)    # 6
print(view.itemsize)  # 1
print(view.shape)     # (6,)
print(view.readonly)  # False — bytearray is writable

# Use memoryview when:
# - Slicing large binary data repeatedly (avoid copies)
# - Passing binary data to I/O without copying (socket.send, file.write accept memoryview)
# - Interfacing with C extensions / numpy that consume the buffer protocol
```

> **When you need `memoryview`:** For most application code, you don't. It matters when profiling shows that slicing/copying large `bytes` objects is a bottleneck, or when working with `numpy`, `socket`, `mmap`, or C extensions that use the buffer protocol.

## 6. Common Operations on `bytes` / `bytearray`

Both types share most of the `str` method set, but operating on bytes with bytes arguments:

```python
# Searching
data = b"hello world, hello Python"
print(data.find(b"hello"))     # 0
print(data.rfind(b"hello"))    # 13
print(data.count(b"hello"))    # 2
print(b"world" in data)        # True

# Splitting
print(b"a,b,c".split(b","))           # [b'a', b'b', b'c']
print(b"a b  c".split())              # [b'a', b'b', b'c'] — whitespace split
print(b"a,b,c,d".rsplit(b",", 1))     # [b'a,b,c', b'd']
print(b"a\nb\r\nc".splitlines())      # [b'a', b'b', b'c']

# Replacing
print(data.replace(b"hello", b"hi"))           # b'hi world, hi Python'
print(data.replace(b"hello", b"hi", 1))        # b'hi world, hello Python'

# Stripping
print(b"  hello  ".strip())           # b'hello'
print(b"www.example.com".strip(b"w."))  # b'example.com' — char set, like str

# Startswith / endswith — accept tuple of bytes
print(data.startswith(b"hello"))                    # True
print(data.endswith(b"Python"))                     # True
print(data.startswith((b"hello", b"hi")))           # True

# Case — only affects ASCII letters
print(b"Hello World".lower())     # b'hello world'
print(b"Hello World".upper())     # b'HELLO WORLD'
print(b"hello world".title())     # b'Hello World'

# Joining — called on bytes separator, takes iterable of bytes
print(b", ".join([b"apple", b"banana", b"cherry"]))  # b'apple, banana, cherry'
# print(b", ".join(["apple", b"banana"]))  # TypeError — must all be bytes

# Decoding back to str — the escape hatch
print(b"hello world".decode("utf-8"))       # hello world
print(b"caf\xc3\xa9".decode("utf-8"))       # café

# Hex
print(b"\xde\xad\xbe\xef".hex())            # deadbeef
print(b"\xde\xad\xbe\xef".hex(" "))         # de ad be ef
print(bytes.fromhex("dead beef"))           # b'\xde\xad\xbe\xef'
```

### Methods That Differ from `str`

```python
# bytes has no .format() or f-string equivalent — use str then encode
name = "Alice"
# f"{name}".encode("utf-8")  # correct — format as str, then encode
message = f"Hello, {name}!".encode("utf-8")
print(message)  # b'Hello, Alice!'

# bytes % formatting — printf-style with bytes (rare, but exists)
print(b"Hello, %s!" % b"Alice")        # b'Hello, Alice!'
print(b"Value: %d" % 42)               # b'Value: 42'

# bytes.fromhex, bytes.hex are bytes-specific
# str has no direct equivalent (use bytes first)

# is* checks work on bytes too — but check byte values 0-255
print(b"hello".isalpha())   # True
print(b"123".isdigit())     # True
print(b"hello123".isalnum())# True
print(b"   ".isspace())     # True
```

## 7. Practical Patterns — When to Use Each

### Pattern 1 — Text Files vs Binary Files

```python
# Text mode — str, with encoding
# with open("notes.txt", "w", encoding="utf-8") as f:
#     f.write("Hello, café! 😀\n")  # str
#
# with open("notes.txt", encoding="utf-8") as f:
#     text: str = f.read()          # str

# Binary mode — bytes, no encoding
# with open("image.png", "rb") as f:
#     data: bytes = f.read()        # bytes — raw file content
#
# with open("output.bin", "wb") as f:
#     f.write(b"\x00\x01\x02\x03")  # bytes

# NEVER mix — writing str to binary file or bytes to text file raises TypeError
import io, tempfile, os
# Demonstrate with in-memory buffers:
text_buf = io.StringIO()
text_buf.write("hello")       # str → StringIO
# text_buf.write(b"hello")    # TypeError

byte_buf = io.BytesIO()
byte_buf.write(b"hello")      # bytes → BytesIO
# byte_buf.write("hello")     # TypeError
```

### Pattern 2 — Network Protocols

```python
# Network I/O is always bytes — you choose the encoding for text payloads.
import json
import struct

# Sending JSON over a socket — str → bytes → wire → bytes → str
payload = {"action": "greet", "name": "Alice", "message": "café 😀"}
json_str: str = json.dumps(payload, ensure_ascii=False)
print(f"JSON str: {json_str!r}")
wire_bytes: bytes = json_str.encode("utf-8")
print(f"Wire bytes: {wire_bytes!r} ({len(wire_bytes)} bytes)")

# Simulate receiving
received_str: str = wire_bytes.decode("utf-8")
received_payload = json.loads(received_str)
print(f"Received: {received_payload}")

# Binary protocol — struct packing (no text at all)
# E.g., a simple header: magic (2 bytes) + version (1 byte) + length (4 bytes BE)
MAGIC = b"\xCA\xFE"
VERSION = 1

def build_packet(data: bytes) -> bytes:
    header = struct.pack(">2sBI", MAGIC, VERSION, len(data))
    # > = big-endian, 2s = 2-byte string, B = uint8, I = uint32
    return header + data

def parse_packet(packet: bytes) -> tuple[int, bytes]:
    magic, version, length = struct.unpack(">2sBI", packet[:7])
    assert magic == MAGIC, f"Bad magic: {magic.hex()}"
    payload = packet[7:7+length]
    assert len(payload) == length
    return version, payload

packet = build_packet(b"hello world")
print(f"Packet: {packet.hex(' ')}")
version, payload = parse_packet(packet)
print(f"Version: {version}, Payload: {payload!r}")
```

### Pattern 3 — Hashing and Crypto (Always Bytes)

```python
import hashlib
import hmac
import os

# Hash functions consume bytes, produce bytes
data = b"hello world"
digest: bytes = hashlib.sha256(data).digest()
print(digest.hex())           # b94d27b9934d3e08a52e52d7da7dabfac484efe37a5380ee9088f7ace2efcde9
print(hashlib.sha256(data).hexdigest())  # same as hex string

# Hashing a string — must encode first
text = "hello world"
# hashlib.sha256(text)  # TypeError: Unicode-objects must be encoded before hashing
print(hashlib.sha256(text.encode("utf-8")).hexdigest())  # correct

# HMAC — also bytes
key = b"secret-key"
print(hmac.new(key, b"message", hashlib.sha256).hexdigest())

# Random bytes — for keys, tokens, nonces
token: bytes = os.urandom(16)
print(token.hex())            # e.g., a3f2c891... — 16 random bytes
print(len(token))             # 16

# Secrets module — for security-sensitive tokens
import secrets
print(secrets.token_hex(16))  # 32 hex chars (16 bytes) — cryptographically strong
print(secrets.token_bytes(16).hex())
print(secrets.token_urlsafe(16))  # URL-safe base64
```

### Pattern 4 — Building Binary Data Incrementally

```python
# Assembling a binary file or packet — bytearray is ideal
def build_bmp_header(width: int, height: int) -> bytes:
    """Build a minimal BMP file header (for illustration)."""
    import struct
    row_size = (width * 3 + 3) & ~3  # rows padded to 4-byte boundary
    pixel_data_size = row_size * height
    file_size = 54 + pixel_data_size  # 54 = header size

    buf = bytearray()

    # BMP file header (14 bytes)
    buf.extend(b"BM")                                    # signature
    buf.extend(struct.pack("<I", file_size))             # file size (little-endian)
    buf.extend(struct.pack("<HHI", 0, 0, 54))            # reserved + pixel offset

    # DIB header (40 bytes — BITMAPINFOHEADER)
    buf.extend(struct.pack("<IiiHHIIiiII", 40, width, height, 1, 24,
                            0, pixel_data_size, 2835, 2835, 0, 0))

    return bytes(buf)  # freeze as immutable bytes

header = build_bmp_header(100, 100)
print(f"BMP header: {len(header)} bytes, {header[:2]!r} magic")
print(header.hex(" ")[:60] + " ...")

# Alternative with struct + join — also efficient
def build_simple_packet(parts: list[bytes]) -> bytes:
    return b"".join(parts)

print(build_simple_packet([b"header:", b"payload", b":footer"]))
# b'header:payload:footer'
```

## 8. Common Mistakes and Pythonic Idioms

| Mistake | Why It Fails | Fix |
|---|---|---|
| `b"café"` | Non-ASCII in bytes literal | `"café".encode("utf-8")` |
| `b"hello" + " world"` | Mixing bytes and str | `b"hello" + b" world"` or `"hello" + " world"` |
| `hashlib.sha256("hello")` | String instead of bytes | `hashlib.sha256("hello".encode())` |
| `open("file.bin").read()` | Text mode for binary file | `open("file.bin", "rb").read()` |
| `bytes_value.decode()` without specifying encoding | Relies on default (usually utf-8, but be explicit) | `bytes_value.decode("utf-8")` |
| `data[0]` expecting `bytes` | `bytes[0]` is `int` | `data[0:1]` for `bytes`, or `chr(data[0])` |
| `bytearray` as dict key | `bytearray` is unhashable | Use `bytes` for keys |
| `result += b"chunk"` in tight loop (large data) | O(n²) copies | `bytearray` + `extend`, or `b"".join(chunks)` |

**Pythonic idioms:**

```python
# Always be explicit about encoding at boundaries
text: str = raw_bytes.decode("utf-8")      # bytes → str
raw_bytes: bytes = text.encode("utf-8")    # str → bytes

# Use bytes for binary protocols, str for text
# Never mix — TypeError is your friend, not your enemy

# Efficient binary assembly
chunks: list[bytes] = [b"part1", b"part2", b"part3"]
combined = b"".join(chunks)                # not repeated +=

# Or for incremental mutation:
buf = bytearray()
buf.extend(b"chunk1")
buf.extend(b"chunk2")
result: bytes = bytes(buf)                 # freeze when done

# Hex for debugging binary data
print(data.hex(" "))                       # readable hex dump

# Hashing — always encode strings first
import hashlib
digest = hashlib.sha256(text.encode("utf-8")).hexdigest()

# File I/O — explicit mode and encoding
# text:  open("file.txt", encoding="utf-8").read()
# binary: open("file.bin", "rb").read()
```

---

## 9. Summary

- **`bytes` is an immutable sequence of `int` (0–255)** — `b"hello"[0]` is `104` (int), not `b"h"`. Slicing returns `bytes`; iterating yields `int`.
- **`str` vs `bytes` is a hard boundary** — they never implicitly convert; mixing them raises `TypeError`. Cross explicitly with `str.encode("utf-8") → bytes` and `bytes.decode("utf-8") → str`.
- **Bytes literals** (`b"..."`) can only contain ASCII; non-ASCII must be via escapes or by encoding a `str`.
- **`bytearray` is the mutable counterpart** — supports `append`/`extend`/`insert`/`pop`/slice assignment. Use it for incremental binary construction. It is unhashable (cannot be a `dict` key); `bytes` is hashable.
- **`memoryview` provides zero-copy views** — slicing a `memoryview` doesn't copy data; useful for large buffers, `socket`/`mmap`/`numpy` interop. Most application code doesn't need it.
- **Common operations** (`find`/`split`/`join`/`replace`/`hex`/etc.) work on `bytes`/`bytearray` with `bytes` arguments — not `str` arguments.
- **Use `bytes` for:** file I/O in binary mode, network I/O, hashing/crypto, binary protocols (`struct`), and anywhere the data is not text. Use `str` for everything human-readable.
- **Efficiency:** `b"".join(chunks)` or `bytearray` + `extend` for building large binary data; `bytes.hex(" ")` for debugging.

> **Key takeaway:** Treat `str` and `bytes` as fundamentally different types that happen to look similar when the content is ASCII. The `encode`/`decode` boundary is where text meets the outside world — always cross it explicitly, always name your encoding (usually `utf-8`), and let `TypeError` catch you when you forget. For binary assembly, reach for `bytearray` or `b"".join`; for large zero-copy work, reach for `memoryview`.
