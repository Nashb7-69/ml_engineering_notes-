# 2.4 Sets and Frozensets

A `set` is an unordered collection of *unique* hashable objects, backed by a hash table just like a `dict`. It is the right tool for membership testing, deduplication, and classic set algebra (union, intersection, difference). `frozenset` is the immutable, hashable counterpart that can live inside other sets or serve as a dictionary key.

## What Sets Are (and Are Not)

A `set` is:

- **Unordered** — no defined position; cannot index or slice; iteration order is arbitrary (hash-dependent, though deterministic within a run).
- **Unique** — duplicates are merged automatically (`{1, 1, 2} == {1, 2}`).
- **Mutable** (plain `set`) — can add/remove elements; unhashable as a result.
- **Elements must be hashable** — `int`, `str`, `tuple` (of hashables), `frozenset`, `None` are fine; `list`, `dict`, `set` are not.
- **O(1) average** `in` membership, unlike lists where `in` is O(n).

```python
# Construction deduplicates and discards order assumptions
data = [3, 1, 2, 2, 3, 1]
unique = set(data)
print(unique)               # {1, 2, 3} — order may vary (randomized hash in practice deterministically shuffled)
print(2 in unique)          # True — O(1)
print(len(unique))          # 3
print(list(unique)[:2])     # don't rely on slice order
```

> **Mental model:** A `set` is a `dict` with only keys (and no values). Internally it shares the dict's hash probe logic. A `frozenset` is the immutable version, just as a tuple is to a list.

## Construction

### Literal Syntax (Braces) — But Not Empty

```python
# Non-empty set literal: braces with values (no colons)
s1 = {1, 2, 3}              # {1, 2, 3}
s2 = {"a", "b", "a"}        # {'a', 'b'} — duplicate removed
print(type(s2))             # <class 'set'>

# Empty literal pitfall:
empty_braces = {}            # THIS IS A DICT, not a set!
print(type(empty_braces))   # <class 'dict'>
empty_set = set()            # correct empty set
empty_fs = frozenset()       # correct empty frozenset
print(empty_set)            # set()

# Mixed types (if hashable and comparable is not needed):
mixed = {1, "a", (1, 2), frozenset([3, 4])}
print(mixed)
# {frozenset(...)} inside sets requires frozenset wrapper; plain set inside fails
# {1, [1, 2]}               # TypeError: unhashable type: 'list'
```

### `set()` and `frozenset()` Constructors

```python
print(set())                # set()
print(set([1, 2, 2, 3]))   # {1, 2, 3} — from any iterable
print(set("hello"))         # {'h', 'e', 'l', 'o'} — characters deduplicated
print(set({"a": 1, "b": 2}))  # {'a', 'b'} — keys only, like dict.keys()
print(set(range(5)))        # {0, 1, 2, 3, 4}

# frozenset analog
fs = frozenset([1, 2, 2, 3])
print(fs)                   # frozenset({1, 2, 3})
print(type(fs))             # <class 'frozenset'>
print(fs | frozenset([3, 4]))  # frozenset({1, 2, 3, 4}) — still frozenset if first is frozenset?
print(frozenset([1, 2]) | {3}) # {1, 2, 3} — operation result often set if mixing; see table below

# From comprehension — set comprehension
print({x*x for x in range(5)})        # {0, 1, 4, 9, 16}
print({c for c in "abracadabra"})     # {'a', 'b', 'r', 'c', 'd'}

# frozenset is constructed explicitly; no literal exists
# No "frozenset comprehension" — use frozenset({...}) or frozenset(x for ...)
fs2 = frozenset(x for x in range(5) if x % 2 == 0)
print(fs2)                  # frozenset({0, 2, 4})
```

> **Idiom:** Prefer `{...}` for non-empty sets (faster, clearer). Use `set()` only for empty sets or converting iterables.

```python
# True deduplication trick: keep insertion order?
# Before 3.7, dict + set tricks needed. Since 3.7, dict.fromkeys preserves order.
data = [3, 1, 2, 2, 3]
dedup_ordered = list(dict.fromkeys(data))
print(dedup_ordered)        # [3, 1, 2] — order-preserving dedup
# Set alone NOT order-preserving:
print(set(data))            # {1, 2, 3} — sorted appearance is incidental, not guaranteed ordering
```

## Set Operations — Algebraic Core

Sets implement mathematical set algebra via operators **and** named methods.

| Operator | Method | Name | Result |
|---|---|---|---|
| `s \| t`, `s.union(t, ...)` | `union` | Union | Elements in **either** |
| `s & t`, `s.intersection(t, ...)` | `intersection` | Intersection | Elements in **both** |
| `s - t`, `s.difference(t, ...)` | `difference` | Difference | In `s` **not** in `t` |
| `s ^ t`, `s.symmetric_difference(t)` | `symmetric_difference` | Symmetric diff | In exactly **one** |
| `s <= t`, `s.issubset(t)` | `issubset` | Subset | All of `s` in `t` |
| `s < t` | — | Proper subset | Subset and not equal |
| `s >= t`, `s.issuperset(t)` | `issuperset` | Superset | `t` subset of `s` |
| `s > t` | — | Proper superset | Superset and not equal |
| `s.isdisjoint(t)` | `isdisjoint` | Disjoint | No overlap |

### Worked Examples

```python
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}

print(a | b)                    # {1, 2, 3, 4, 5, 6}
print(a & b)                    # {3, 4}
print(a - b)                    # {1, 2}
print(b - a)                    # {5, 6}
print(a ^ b)                    # {1, 2, 5, 6}

# Named methods accept many iterables, not just sets:
print(a.union([5, 6], (7, 8)))  # {1,2,3,4,5,6,7,8}
print(a.intersection([2, 3, 99]))

# Chaining
c = {2, 3}
print((a & b) & c)              # {3}
# Or: set.intersection(a, b, c) as n-ary

# Subset / superset / disjoint
print({1, 2} <= {1, 2, 3})      # True
print({1, 2} < {1, 2})          # False — not proper
print({1, 2} >= {1})            # True
print({1, 2}.isdisjoint({3, 4})) # True
print({1, 2}.isdisjoint({2, 3})) # False

# Operator vs method: operator requires both operands to be sets
# print({1, 2} | [3, 4])  # TypeError — | requires sets; .union([3,4]) works

# Frozenset operations mirror set:
fs_a = frozenset([1, 2, 3])
fs_b = frozenset([3, 4])
print(fs_a | fs_b)              # frozenset({1, 2, 3, 4})
print(fs_a - fs_b)              # frozenset({1, 2})
```

```python
# Realistic: permission model
required = {"read", "write"}
user = {"read", "execute", "write"}
print(required <= user)         # True — user has all required
missing = required - user
print(missing)                  # set() — none missing

peer = {"read", "write"}
print(required == peer)         # True — equality is set equality (order & duplicates irrelevant)

# Tag filtering
article_tags = {"python", "data", "ml"}
filter_tags = {"python", "web"}
print(article_tags & filter_tags)   # {'python'} — relevant
```

### In-Place Operators (Mutable `set` Only)

| Operator | Method | Effect |
|---|---|---|
| `s \|= t` | `s.update(t)` | Union in place |
| `s &= t` | `s.intersection_update(t)` | Intersect in place |
| `s -= t` | `s.difference_update(t)` | Difference in place |
| `s ^= t` | `s.symmetric_difference_update(t)` | Sym diff in place |

```python
s = {1, 2}
s |= {3, 4}                 # {1, 2, 3, 4} — same as s.update([3,4])
s &= {2, 3}                 # {2, 3}
s -= {3}                    # {2}
s ^= {4, 5}                 # {2, 4, 5}
print(s)

# update accepts many iterables:
s = {1}
s.update([2, 3], "ab", {4: "ignored"}, (5, 6))
print(s)                    # {1, 2, 3, 'a','b', 4, 5, 6} — dict keys added
```

## Methods — Complete Reference

### Add/Remove (Mutable `set`)

```python
s = set()

# add(elem) — insert one
s.add(1)
s.add(1)                    # duplicate ignored — no error, still {1}
print(s)

# remove(elem) — raises KeyError if absent
s.add(2)
s.remove(2)
print(s)                    # {1}
# s.remove(99)              # KeyError

# discard(elem) — no error if absent
s.discard(99)               # silent
s.discard(1)
print(s)                    # set()

# pop() — remove and return an ARBITRARY element
s = {10, 20, 30}
elem = s.pop()
print(elem, s)              # e.g. 10 {20, 30} — arbitrary, not "last" or "first"
# s.pop() on empty -> KeyError
# Do NOT rely on which element pop() returns.

# clear() — empty the set
s.clear()
print(s)                    # set()

# Realistic: worklist algorithm
remaining = {"a", "b", "c"}
while remaining:
    item = remaining.pop()
    print(f"processing {item}")
```

### Queries (Both `set` and `frozenset`)

```python
s = {1, 2, 3}
print(len(s))               # 3 — O(1)
print(1 in s)               # True — O(1) average
print(9 not in s)           # True

# copy() — shallow copy
t = s.copy()                # s.copy() or set(s) or copy.copy(s)
print(t is s, t == s)       # False True

# Iteration
for x in s:
    print(x)                # order not defined

# Membership performance vs list — dramatic for large n
# if x in huge_set:  # O(1)
# if x in huge_list: # O(n)

# Comparisons
print({1} < {1, 2})        # True — proper subset
print({1, 2} == {2, 1})    # True — order irrelevant
```

## `frozenset` — The Immutable, Hashable Set

```python
# frozenset is immutable — no add/remove/update/discard/pop/clear
fs = frozenset([1, 2, 3])
# fs.add(4)                # AttributeError: 'frozenset' object has no attribute 'add'
# fs.discard(1)            # AttributeError

# But query and algebra still work
print(len(fs))              # 3
print(2 in fs)              # True
print(fs | frozenset([3, 4]))  # frozenset({1, 2, 3, 4})
print(fs & {2, 3})          # frozenset({2, 3})? Actually {2,3} set? See below

# Crucial: hashable when elements hashable -> can be set element or dict key
sets_of_sets = {frozenset([1, 2]), frozenset([3, 4])}
print(sets_of_sets)
# {frozenset([3,4]), frozenset([1,2])}

edges = {
    frozenset(["a", "b"]): 10,   # undirected edge — order-insensitive
    frozenset(["b", "c"]): 20,
}
# frozenset({"a","b"}) == frozenset({"b","a"}) -> same key (set equality)
print(edges[frozenset(["b", "a"])])  # 10

# Useful: counting distinct subsets, caching set arguments, deduplicating sets
def memoized_with_sets(func):
    cache = {}
    def wrapper(*sets):
        key = frozenset(sets) if len(sets) == 1 else tuple(frozenset(s) for s in sets)
        # but tuple can't hold set directly — must convert
        return cache.get(key)
    return wrapper
```

### Set vs Frozenset — Type Table

|  | `set` | `frozenset` |
|---|---|---|
| Mutable | Yes | **No** |
| Hashable | **No** (`TypeError`) | **Yes** (if elements hashable) |
| Dict key / set member | No | Yes |
| Methods `add`/`remove`/`pop` | Yes | No (raises `AttributeError`) |
| Operators `& \| - ^` | Yes → `set` | Yes → `frozenset` when both `frozenset` |
| Literal | `{1,2}` | None — use `frozenset(...)` |
| Comprehension | `{x for x in ...}` | `frozenset(x for x in ...)` |

```python
# Operator return type subtlety:
# set OP set  -> set
# frozenset OP frozenset -> frozenset
# set OP frozenset / frozenset OP set -> set (if left is set; actually CPython may return type of left)
print(type(frozenset([1,2]) | frozenset([3])))  # <class 'frozenset'>
print(type({1,2} | frozenset([3])))            # <class 'set'>
# .union/.intersection methods return type matching caller (self type)
```

## Set Comprehension and Generator Notes

```python
# Set comprehension — same syntax as dict but with one expression
print({x*x for x in range(5)})              # {0, 1, 4, 9, 16}
print({word[0] for word in ["apple", "avocado", "banana"]})  # {'a', 'b'}

# With condition
print({x for x in range(10) if x % 2 == 0}) # {0, 2, 4, 6, 8}

# Empty set comprehension? No — {} is dict; {for x in y} is not legal. Use set().
# set comprehension of generator:
print({x for x in []})      # set() — empty set via comprehension

# frozenset from comprehension/generator
print(frozenset({x for x in range(5)}))     # frozenset({0, 1, 2, 3, 4})
print(frozenset(x for x in range(5) if x % 2 == 0))  # generator directly
```

## Membership Performance — The Reason to Use Sets

```python
# Membership is the killer feature
# list: O(n) scan
# set/dict/frozenset: O(1) hash probe

# Realistic: filtering large stream
allowed = {"admin", "editor", "viewer"}  # set
users = ["admin", "ghost", "editor"] * 1000
# Fast membership:
filtered = [u for u in users if u in allowed]

# Bad: using list for membership
# allowed_list = ["admin", "editor", "viewer"]
# if u in allowed_list:  # O(n) per check -> O(n*m)

# Even for small n, set communicates intent: "membership testing"
# For very small (2–3 elements), performance difference is negligible;
# clarity is the win.

# Negated membership is also O(1):
# if token not in banned:
```

## When to Use Sets vs Other Collections

| Need | Choose |
|---|---|
| Collect unique items, no order needed | `set` |
| Membership tests dominant (`in` checks) | `set` / `frozenset` |
| Need hashable set to use as `dict` key or inside another set | `frozenset` |
| Need order + uniqueness | `dict.fromkeys(...)` (3.7+), or `ordered-set` library, or maintain a `list` + `set` together |
| Need indexing, ordering, duplicates allowed | `list` / `tuple` |
| Count distinct, compare overlaps | `set` algebra |
| Represent relation/graph edges undirected | `frozenset` of two nodes |

```python
# Order + uniqueness pattern: preserve insertion order
def unique_ordered(seq):
    seen = set()
    result = []
    for x in seq:
        if x not in seen:
            seen.add(x)
            result.append(x)
    return result

print(unique_ordered([3, 1, 2, 2, 3, 1]))  # [3, 1, 2]
# Python 3.7+ alternative: list(dict.fromkeys(seq)) — concise, C-fast
print(list(dict.fromkeys([3, 1, 2, 2, 3, 1])))  # [3, 1, 2]
```

## Hashability and Nested Pitfalls

```python
# Elements must be hashable — recursively
# ok:
print(hash((1, (2, 3))))
print(hash(frozenset([1, 2])))

# not ok — tuple containing mutable -> unhashable
# s = {(1, [2, 3])}  # TypeError: unhashable type: 'list'
# s = {{1, 2}}       # TypeError: unhashable type: 'set' -> use frozenset

# Subtle: bool is a subclass of int — True == 1 and hash collisions
print({1, True, 1.0})       # {1} — all equal/hashed same -> deduplicated to one
print({0, False, 0.0})      # {0}
print(len({1, 1.0, True}))  # 1

# None handling:
print({None, None})         # {None}

# Equality comparisons of elements use == after hash match:
s = {1, "1"}                # 1 != "1" -> both present
print(s, len(s))            # {1, '1'} 2

# Copy is shallow — inner references shared (though elements should be immutable anyway)
s = {frozenset([1, 2])}     # inner is frozenset; sharing is moot as frozenset immutable
```

## Iteration and No Ordering Guarantees

```python
s = {3, 1, 2}
print(s)                    # {1, 2, 3} might print sorted due to hash of ints; don't depend!
# Strings/objects may appear "randomly" ordered due to hash randomization (PYTHONHASHSEED)
# Since Python 3.3, str/bytes hash is randomized per run — set iteration order changes across runs
# If you need sorted order: sorted(s)

for x in sorted(s):         # deterministic order
    print(x)

# Cannot index:
# s[0]                      # TypeError: 'set' object is not subscriptable
# Cannot slice
# s[0:2]                    # same

# If you need index-like access plus uniqueness, maintain both structures
# or use collections.abc.Sequence wrappers.
```

## Realistic Examples

```python
# 1. Deduplication
raw = ["python", "java", "python", "go", "java"]
print(list(set(raw)))       # deduplicated, unordered — may be ['python','java','go'] in some order
print(sorted(set(raw)))     # deduplicated + sorted

# 2. Filtering + finding missing
required_fields = {"name", "age", "email"}
provided = {"name": "Alice", "age": 30}
missing = required_fields - provided.keys()  # {'email'}
extra = provided.keys() - required_fields    # set()
print(missing, extra)

# 3. Common friends (intersection) and exclusives (sym diff)
alice_friends = {"bob", "carol", "dave"}
bob_friends = {"carol", "dave", "eve"}
print(alice_friends & bob_friends)   # mutual: {'carol','dave'}
print(alice_friends ^ bob_friends)   # exclusive: {'bob','eve'}
print(alice_friends - bob_friends)   # only Alice's: {'bob'}

# 4. Word unique characters
word = "abracadabra"
unique_chars = set(word)
print(unique_chars)         # set of distinct characters

# 5. Graph nodes as frozenset edges (undirected)
edges = {frozenset({"a", "b"}), frozenset({"b", "c"}), frozenset({"a", "c"})}
print(edges)
# Adding duplicate edge (order-insensitive) is a no-op:
edges.add(frozenset({"b", "a"}))
print(edges)                # unchanged

# 6. Membership caching with frozenset keys
cache = {frozenset([1, 2]): "computed result"}
print(cache[frozenset([2, 1])])  # 'computed result' — same set

# 7. Data cleaning: invalid chars removal
allowed = set("abcdefghijklmnopqrstuvwxyz0123456789_")
raw_tags = ["hello!", "world?", "ok_tag"]
cleaned = ["".join(ch for ch in tag if ch in allowed) for tag in raw_tags]
print(cleaned)              # ['hello', 'world', 'ok_tag']
```

## Common Mistakes

```python
# 1. {} is dict, not set
print(type({}))            # dict — use set() for empty

# 2. Trying to use list/dict/set as element
# { [1,2] }                 # TypeError: unhashable
# Fix: tuple or frozenset
print({tuple([1, 2])})     # {(1, 2)}
print({frozenset([1, 2])})

# 3. Assuming order/indexing
# s = {1, 2, 3}; s[0]      # TypeError

# 4. Expecting pop() to return "last" element
s = {1, 2, 3}
print(s.pop())              # arbitrary element — not sorted, not last inserted

# 5. Modifying set while iterating — RuntimeError or skipped semantics
# for x in s: s.remove(x)  # RuntimeError: Set changed size during iteration
# Fix: iterate over copy
s = {1, 2, 3, 4}
for x in list(s):
    if x % 2 == 0:
        s.remove(x)
print(s)                    # {1, 3}

# 6. Using set for tiny, constant membership tests when frozenset would be hashable/constant
# Bad for default arg:
# def fn(valid={1, 2}): ...  # set is mutable and unhashable, but also shared! Use frozenset or None.
# Good:
ALLOWED = frozenset([1, 2])  # immutable, hashable, shared safely
# or:
# def fn(valid=None):
#     if valid is None: valid = {1, 2}

# 7. Forgetting that operator requires sets, method accepts iterables
print({1, 2}.union([2, 3]))    # {1, 2, 3} — method works with list
# print({1, 2} | [2, 3])      # TypeError — operator fails
```

## Summary

- A `set` is an unordered, unique, mutable collection with O(1) membership; `frozenset` is its immutable, hashable counterpart.
- Create with `{1, 2, 3}` (non-empty), `set(iterable)`, or set comprehensions `{x for x in iter}`; frozenset only via `frozenset(iterable)`. Empty `{}` is a dict.
- Core algebra: union `|`, intersection `&`, difference `-`, symmetric difference `^`, subset `<=`/`<`, superset `>=`/`>`, disjointness `isdisjoint()` — both operator and method forms.
- Mutating methods (`add`, `discard`, `remove`, `pop`, `clear`, `update`/`|=` etc.) exist only on `set`.
- Use sets to dominate membership tests; never use `x in list` in a hot loop for large `n`.
- If you need ordering + uniqueness, combine `dict.fromkeys` or a `list`+`set` pair; `frozenset` is essential for using sets as `dict` keys or set elements (e.g., undirected graph edges).
