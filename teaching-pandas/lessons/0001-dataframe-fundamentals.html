Lesson 1: DataFrame Fundamentals

Mission context: Before we can clean data for ML, we need to understand what a DataFrame is — its anatomy, how it differs from NumPy arrays, and why its design matters for ML pipelines.

What Is a DataFrame?

A DataFrame is a two-dimensional, size-mutable, tabular data structure with labeled axes (rows and columns). Think of it as:

  • A spreadsheet in memory
  • A SQL table you can manipulate with Python
  • A dict of Series sharing the same index
  • A collection of columns, each a 1D NumPy array, aligned by a shared row index

Mental Model for ML

Each row = one observation (sample). Each column = one feature (or target). This maps directly to X (features) and y (target) in scikit-learn.

Anatomy of a DataFrame

import pandas as pd
import numpy as np

df = pd.DataFrame({
    "age": [25, 32, 47, 51],
    "income": [50000, 80000, 120000, 95000],
    "city": ["NYC", "LA", "Chicago", "Boston"]
})

print(df)
#    age  income     city
# 0   25   50000      NYC
# 1   32   80000       LA
# 2   47  120000  Chicago
# 3   51   95000   Boston

Creating DataFrames: The ML-Relevant Ways

1. From a dict of lists (column-oriented)

data = {
    "feature_1": [1.2, 3.4, 2.1],
    "feature_2": [0, 1, 0],
    "target":    [10, 20, 15]
}
df = pd.DataFrame(data)

2. From a list of dicts (row-oriented)

records = [
    {"feature_1": 1.2, "feature_2": 0, "target": 10},
    {"feature_1": 3.4, "feature_2": 1, "target": 20},
]
df = pd.DataFrame(records)

3. From NumPy arrays (when you have raw matrices)

X = np.array([[1.2, 0], [3.4, 1], [2.1, 0]])
y = np.array([10, 20, 15])

df = pd.DataFrame(X, columns=["feat_1", "feat_2"])
df["target"] = y

⚠ Column Order Matters

In Python < 3.7, dicts weren't ordered. Always pass columns=[...] explicitly when creating from NumPy arrays or when column order matters for your ML pipeline.

DataFrame vs. NumPy Array: Why Both Exist

AspectNumPy Arraypandas DataFrame
DimensionsN-dimensionalStrictly 2D
DtypesHomogeneous (one dtype)Heterogeneous per column
LabelsInteger positions onlyNamed index + columns
Missing dataNo native supportNaN / NA first-class
AlignmentManualAutomatic on index
ML roleModel input (X, y)Preprocessing, EDA, feature engineering

Workflow: Load → Clean/Transform in pandas → .to_numpy() or .values → Feed to model.

Essential Inspection Methods

df.head(3)        # First 3 rows
df.tail(2)        # Last 2 rows
df.info()         # Columns, non-null counts, dtypes, memory
df.describe()     # Summary stats for numeric columns
df.describe(include="all")  # Include object/categorical
df.shape          # (rows, cols)
df.columns        # Column names (Index object)
df.dtypes         # Dtype per column
df.index          # Row index

💡 ML Tip: df.info() First

Always run df.info() on new data. It reveals: missing values (non-null count), wrong dtypes (e.g., numbers read as object), and memory usage — all critical before modeling.

Hands-On Exercise

Open a Python REPL or Jupyter notebook and run:

import pandas as pd
import numpy as np

# 1. Create a DataFrame from this dict
data = {
    "sepal_length": [5.1, 4.9, 4.7, 4.6, 5.0],
    "sepal_width":  [3.5, 3.0, 3.2, 3.1, 3.6],
    "species":      ["setosa", "setosa", "setosa", "setosa", "setosa"]
}
df = pd.DataFrame(data)

# 2. Inspect it
print("Shape:", df.shape)
print("\nDtypes:\n", df.dtypes)
print("\nInfo:")
df.info()
print("\nDescribe:\n", df.describe())

# 3. Convert to NumPy (features only)
X = df[["sepal_length", "sepal_width"]].to_numpy()
print("\nX shape:", X.shape)
print("X dtype:", X.dtype)

Expected output: X shape: (5, 2), X dtype: float64.

Key Takeaways

  1. A DataFrame = labeled columns (Series) sharing a row index
  2. Columns can have different dtypes; rows are aligned by index
  3. Use df.info() first on new data — it's your diagnostic dashboard
  4. Convert to NumPy with .to_numpy() for model input
  5. Column order matters — be explicit with columns=[...]
