# Resources: pandas DataFrames for ML Data Analysis

## Primary Sources (Highest Trust)

### Official Documentation
- **[pandas User Guide](https://pandas.pydata.org/docs/user_guide/index.html)** — The authoritative guide. Start with "10 minutes to pandas" then "Essential Basic Functionality"
- **[pandas API Reference](https://pandas.pydata.org/docs/reference/index.html)** — Complete method/class reference. Use for looking up specific functions.
- **[pandas Cookbook](https://pandas.pydata.org/docs/user_guide/cookbook.html)** — Practical recipes for common tasks.

### Books
- **"Python for Data Analysis" (3rd ed.) by Wes McKinney** — Written by pandas creator. Chapters 3-8 cover DataFrames deeply. *Essential reference.*
- **"Effective Pandas" by Matt Harrison** — 63 specific ways to write better pandas. Great for patterns and anti-patterns.
- **"Pandas in Action" by Boris Paskhaver** — Tutorial-style with real datasets. Good for beginners.

### ML-Specific Resources
- **[Feature Engineering for Machine Learning by Alice Zheng & Amanda Casari](https://www.oreilly.com/library/view/feature-engineering-for/9781491953235/)** — Chapter 3-4 use pandas extensively for feature creation.
- **[Kaggle pandas Course](https://www.kaggle.com/learn/pandas)** — Free, hands-on, uses real ML competition data.
- **scikit-learn docs: [Preprocessing data](https://scikit-learn.org/stable/modules/preprocessing.html)** — Shows how pandas DataFrames feed into sklearn transformers.

## Secondary Sources (High Quality)

### Blogs & Articles
- **[Modern Pandas by Tom Augspurger](https://tomaugspurger.github.io/modern-1.html)** — Deep dives into internals, indices, performance. *Highly recommended for mental models.*
- **[pandas.dev blog](https://pandas.pydata.org/blog/)** — Release notes and deep-dive articles from core developers.
- **[Data School by Kevin Markham](https://www.dataschool.io/)** — Clear tutorials on pandas for ML workflows.

### Video Courses
- **[pandas official tutorial (YouTube)](https://www.youtube.com/playlist?list=PL5-da3qGB5IBLMp7LtN8Nc3Efd4hJq0kD)** — From pandas maintainers.
- **[Corey Schafer pandas playlist](https://www.youtube.com/playlist?list=PL-osiE80TeTsWmV9i9c58mdDCSskIFdDS)** — Beginner-friendly, well-paced.

## Reference & Cheat Sheets
- **[pandas Cheat Sheet (official PDF)](https://pandas.pydata.org/Pandas_Cheat_Sheet.pdf)** — One-page syntax reference.
- **[Data Wrangling Cheat Sheet](https://github.com/pandas-dev/pandas/blob/main/doc/cheatsheet/Pandas_Cheat_Sheet.pdf)** — Focused on cleaning/transforming.

## Community & Help
- **[Stack Overflow pandas tag](https://stackoverflow.com/questions/tagged/pandas)** — Search before asking; most questions already answered.
- **[pandas GitHub Discussions](https://github.com/pandas-dev/pandas/discussions)** — For bugs, feature requests, and design questions.
- **/r/pandas** — Reddit community for questions and tips.

## Datasets for Practice (ML-Relevant)
- **[UCI ML Repository](https://archive.ics.uci.edu/ml/index.php)** — Classic benchmark datasets.
- **[Kaggle Datasets](https://www.kaggle.com/datasets)** — Real-world, messy, with kernels showing pandas usage.
- **[OpenML](https://www.openml.org/)** — Curated for ML benchmarking.
- **seaborn.load_dataset()** — Built-in: `tips`, `titanic`, `iris`, `penguins`, `diamonds` — great for quick experiments.

---

**How to use these**: Start with the "10 minutes to pandas" tutorial, then use the User Guide as your textbook. Keep the Cheat Sheet open while practicing. When stuck, search Stack Overflow. For deep understanding, read Modern Pandas articles.
