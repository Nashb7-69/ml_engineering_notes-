# Mission: pandas DataFrames for ML Data Analysis

## Why This Matters

I want to learn pandas DataFrames deeply because they are the **primary tool for preparing, cleaning, and transforming structured data before feeding it into machine learning models**. Real-world ML workflows spend 70-80% of time on data preparation, and pandas is the industry-standard library for this.

## Concrete Goals

1. **Load & inspect** data from common ML sources (CSV, Parquet, SQL)
2. **Clean & validate** data: handle missing values, fix types, detect outliers
3. **Feature engineering**: create new columns, encode categoricals, scale numerical features
4. **Train/test splits**: properly partition data without leakage
5. **Pipeline integration**: export clean DataFrames to NumPy arrays / tensors for model training

## Success Criteria

- Can take a raw, messy CSV and produce a model-ready DataFrame in < 30 minutes
- Understands *why* each transformation matters for ML (not just *how*)
- Can debug common pandas issues (SettingWithCopyWarning, dtype issues, index misalignment)
- Has a mental model of DataFrame internals (blocks, indices, dtypes) for performance

## Current Level

- Knows basic Python, NumPy arrays, and pandas Series
- Has seen DataFrame syntax but lacks deep understanding
- Wants to move from "copy-paste pandas" to "intentional pandas"

## Constraints

- Lessons should be **short** (10-15 min each) and **action-oriented**
- Each lesson must connect to an ML use case
- Prefer hands-on practice over passive reading
- Build a reusable reference library for future projects
