> series is a Pandas 1-Dimensional labeled array that can hold any data type think of it like a single column in a **spreadsheet**

# what dose that mean 
it allows you to make a key value out of any datatype such as list [[0.2 Numpy arrays|Numpy Arrays]]

``` python 
import pandas as  pd 
data=[100,102,104]
series = pd.Series(data)
print(series)
#output 
#0    100
#1    102
#2    104
#dtype: int64

```

## what changed 

> it's now assigned to a key value for easier access 

notice that it showed us the data type as in [[0.9 Dtypes + astype]]
so changing the value change it dtype since pandas is built over NumPy

``` python 
import pandas as  pd 
data=["A","B","C"]
series = pd.Series(data)
print(series)
# output 
#0    A
#1    B
#2    C
#dtype: object
```


## Indexing 
to add a costume key to the values 
make sure that the length of values matches index length 
``` python 
import pandas as  pd 
data=[100,102,104]
series = pd.Series(data,index=["a","b","c"])
print(series)

#output 
#a    100
#b    102
#c    104
#dtype: int64

```

## Loc (location)
used to show a value by it key 
```python
import pandas as  pd 
data=[100,102,104]
series = pd.Series(data,index=["a","b","c"])
print(series.loc["c"])
# output
#104
```


## iloc (integer location) 
used to show the value of an index in the serise
``` python
import pandas as  pd 
data=[100,102,104]
series = pd.Series(data,index=["a","b","c"])
print(series.iloc[1])
# output 
#102
```


## filtering
everything here is the same as [[0.7 filtering|filtering in NumPy]] 
``` python
import pandas as pd 
data=[100,102,104,200,202]
series = pd.Series(data,index=["a","b","c","d","e"])
print(series[series>=200])
 
 #output 
#d    200
#e    202

```
