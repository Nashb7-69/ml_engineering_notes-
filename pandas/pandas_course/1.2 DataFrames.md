## ⚡ Quick Peek

| I want... | Code |
|---|---|
| Size / cols | `df.shape` / `df.columns.tolist()` |
| Health | `df.info()` / `df.describe()` |
| Peek | `df.head(2)` / `df.tail(2)` |
| 1 col (Series) | `df["Name"]` |
| 2+ cols (table) | `df[["Name","Weight"]]` |
| New col | `df["BMI"] = df["Weight"] / (df["Height"]**2)` |
| Rename | `df.rename(columns={"Type1":"Primary"})` |
| Drop col/row | `df.drop(columns=["Legendary"])` / `df.drop(index=[0])` |
| Sort | `df.sort_values("Weight", ascending=False)` |
| Name index | `df.set_index("Name")` / `df.reset_index()` |

Setup:

```python
import pandas as pd
df = pd.read_csv("/home/ravox/machine_learning/code/pokemon.csv")
df.columns = df.columns.str.replace("␍", "", regex=False).str.strip()
```

## See shape

```python
print(df.shape)  # (150, 7)
print(df.columns.tolist())
```

```python
df.info()  # non-null counts: Type2 only 67, rest 150
```

```python
print(df[["Height", "Weight"]].describe().round(2).to_string())
# Height mean 1.20, Weight mean 46.23, max 460.0
```

## Pick / add columns

One col = Series. Two cols = table. Watch brackets:

```python
print(type(df["Name"]))     # Series
print(type(df[["Name"]]))   # DataFrame
```

New column — does all 150 rows at once, no loop:

```python
df["BMI"] = df["Weight"] / (df["Height"] ** 2)
```

True/False column:

```python
df["IsWater"] = df["Type1"] == "Water"
```

## Rename / drop

Does: returns new table, original safe.

```python
df2 = df.rename(columns={"Type1": "Primary"})
```

```python
df_no_leg = df.drop(columns=["Legendary"])
```

```python
df_no_0 = df.drop(index=[0])  # drop Bulbasaur
```

## Sort / index

```python
print(df.sort_values("Weight", ascending=False)[["Name","Weight"]].head(3).to_string())
# Snorlax 460 top
```

Name lookup:

```python
df_idx = df.set_index("Name")
print(df_idx.loc["Pikachu", "Weight"])
```

> [!warning] Slice then edit? Add `.copy()`:
> ```python
> fire = df[df["Type1"] == "Fire"].copy()
> ```

## Reference

| Method | What | When |
|---|---|---|
| `.shape/.columns/.dtypes` | structure | inspect |
| `.info/.describe/.head` | summary | EDA |
| `df[[a,b]]` | subset | pick cols |
| `df[x]=...` | new col | feature |
| `.rename/.drop` | restructure | clean |
| `.sort_values` | order | heaviest first |
| `.set_index/.reset_index` | labels | name lookup |
| `.copy` | safe slice | avoid warning |
