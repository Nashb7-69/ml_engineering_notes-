## ⚡ Quick Peek — peek here when you forget

| I want... | Code |
|---|---|
| Open CSV | `df = pd.read_csv(path)` |
| Row labels = Name | `pd.read_csv(path, index_col="Name")` |
| Only some columns | `pd.read_csv(path, usecols=["Name","Weight"])` |
| Just preview | `pd.read_csv(path, nrows=5)` |
| Fix `;` file | `pd.read_csv(path, sep=";")` |
| Fix decode error | `pd.read_csv(path, encoding="latin1")` |
| Open JSON | `pd.read_json(path)` |
| Save | `df.to_csv("out.csv", index=False)` |
| Health check | `df.shape` , `df.info()` , `df.isna().sum()` |

Copy-paste setup:

```python
import pandas as pd
PATH = "/home/ravox/machine_learning/code/pokemon.csv"
df = pd.read_csv(PATH)
```

## Open + peek (the 95% case)

**Does:** opens file → table in memory.

```python
df = pd.read_csv(PATH)
print(df.shape)  # (150, 7)
```

**Does:** shows first 3 rows. Always do this.

```python
print(df.head(3).to_string())
# 1 Bulbasaur Grass Poison ... 4 Charmander Fire NaN ...
```

Last rows:

```python
print(df.tail(1).to_string())  # Mewtwo
```

## Options you actually need

**Row labels = Pokémon names.** Does: lets you use `df.loc["Pikachu"]` later.

```python
df2 = pd.read_csv(PATH, index_col="Name")
```

**Only needed columns.** Does: faster, cleaner.

```python
df_small = pd.read_csv(PATH, usecols=["Name", "Type1", "Weight"])
```

**Preview big file.** Does: reads first 5 rows only.

```python
df_prev = pd.read_csv(PATH, nrows=5)
```

**Other knobs — just recognize them:**

```python
df = pd.read_csv(PATH, sep=",", header=0, encoding="utf-8")
# sep=";" if file uses semicolons
# encoding="latin1" if you get UnicodeDecodeError
```

## Health check (3 lines, every time)

**Does:** types + missing counts.

```python
print(df.dtypes.to_string())
print(df.isna().sum().to_string())
# Type2 83 missing. Legendary is object = needs fixing later.
```

> [!warning] Errors
> - `FileNotFoundError` → wrong path, copy PATH above
> - `ParserError` → try `sep=";"`
> - See `␍` → normal, we fix in [[3.2 Data Cleaning]]

## Reference

| Method | What | When |
|---|---|---|
| `read_csv` | open CSV | always |
| `index_col` | set labels on load | lookup by Name |
| `usecols` | subset cols | big files |
| `nrows` | first N rows | preview |
| `sep / encoding` | fix parse | broken files |
| `read_json / excel / parquet / sql` | other sources | APIs, Excel, DB |
| `to_csv(index=False)` | save | export |
