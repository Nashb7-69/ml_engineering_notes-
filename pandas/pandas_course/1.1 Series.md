## ⚡ Quick Peek

| I want... | Code |
|---|---|
| Get column | `s = df["Name"]` |
| Peek | `s.head(3)` , `s.tail(2)` , `s.sample(2)` |
| Summary | `s.describe()` |
| Count each | `df["Type1"].value_counts()` |
| Unique list / number | `s.unique()` / `s.nunique()` |
| Sort | `s.sort_values(ascending=False)` |
| Translate | `s.map({"Fire":"FIRE"})` |
| Length of each name | `df["Name"].apply(len)` |
| Lowercase / search | `s.str.lower()` / `s.str.contains("saur")` |
| Missing | `s.isna().sum()` / `s.fillna("None")` |
| Average / max | `s.mean()` / `s.max()` / `s.idxmax()` |

Setup:

```python
import pandas as pd
df = pd.read_csv("/home/ravox/machine_learning/code/pokemon.csv")
df.columns = df.columns.str.replace("␍", "", regex=False).str.strip()
# No loop. .str works on all column names at once.
```

## Get a Series

**Does:** pulls one column out. Single brackets = Series.

```python
names = df["Name"]  # Series, 150 items
print(names.head(2).to_string())
```

Double brackets = table with one column. Different!

```python
print(df[["Name"]].head(2).to_string())  # DataFrame
```

## Inspect

```python
s = df["Name"]
print(s.dtype)  # object = text
print(s.shape)  # (150,)
print(s.name)   # 'Name'
```

```python
print(df["Weight"].describe().to_string())
# mean 46.23, min 0.1, max 460.0 Snorlax
```

```python
print(df["Type1"].describe().to_string())
# top Water, freq 28
```

## Count — most useful

```python
print(df["Type1"].nunique())  # 15 types
```

```python
print(df["Type1"].value_counts().head(5).to_string())
# Water 28, Normal 22, Poison 14, Fire 12, Grass 12
```

 percents:

```python
print(df["Type1"].value_counts(normalize=True).round(2).head(3).to_string())
```

## Sort

```python
print(df["Weight"].sort_values(ascending=False).head(3).to_string())
# Snorlax on top
```

## Change values — which tool?

| Tool | Simple rule | Code |
|---|---|---|
| `map` | translate via dict | `df["Type1"].map({"Fire":"FIRE"})` |
| `apply` | run function each row | `df["Name"].apply(len)` → 9,7,8 |
| `str` | text ops | `df["Name"].str.contains("saur").sum()` → 3 |

```python
print(df["Type1"].map({"Fire": "FIRE", "Water": "WATER"}).head(4).to_string())
# no match = NaN
```

```python
print(df["Name"].str.lower().head(2).to_string())
```

## Missing + math

```python
print(df["Type2"].isna().sum())  # 83 missing
```

```python
print(df["Type2"].fillna("None").head(4).to_string())
```

```python
print(df["Weight"].mean())  # 46.23
print(df["Weight"].max())   # 460.0
```

Tallest name:

```python
print(df.loc[df["Height"].idxmax(), "Name"])  # Onix
# idxmax = row number of max. loc gets name there.
```

Convert:

```python
print(df["Name"].to_list()[:3])  # to Python list
```

## Reference

| Method | What | Example |
|---|---|---|
| `df[col]` | get Series | `df["Name"]` |
| `.dtype/.shape/.name` | describe | `s.dtype` |
| `.head/.tail/.sample` | peek | `s.head()` |
| `.describe` | summary | `s.describe()` |
| `.value_counts` | freq | `df["Type1"].value_counts()` |
| `.unique/.nunique` | distinct | `s.nunique()` → 15 |
| `.sort_values` | sort | `s.sort_values()` |
| `.map/.apply/.str` | transform | `s.str.contains()` |
| `.isna/.fillna` | missing | `s.fillna("None")` |
| `.mean/.max/.idxmax` | math | `s.mean()` |
