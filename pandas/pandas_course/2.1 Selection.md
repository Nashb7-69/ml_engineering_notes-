## ⚡ Quick Peek — which one do I need?

| I want... | Use | Code |
|---|---|---|
| Columns | `[]` | `df[["Name","Weight"]]` |
| Row by name | `.loc` | `df.loc["Pikachu", "Weight"]` |
| Row by number | `.iloc` | `df.iloc[0, 1]` |
| First 3 rows | `.iloc` | `df.iloc[0:3]` |
| One fast cell | `.at` / `.iat` | `df.at[0,"Name"]` |
| Sentence filter | `.query` | `df.query("Weight > 100")` |
| Cols by pattern | `.filter` | `df.filter(like="Type")` |
| Number cols only | `.select_dtypes` | `df.select_dtypes("number")` |

Rule: **name → loc, number → iloc.**

Setup:

```python
import pandas as pd
df = pd.read_csv("/home/ravox/machine_learning/code/pokemon.csv")
df.columns = df.columns.str.replace("␍", "", regex=False).str.strip()
df_name = pd.read_csv("/home/ravox/machine_learning/code/pokemon.csv", index_col="Name")
df_name.columns = df_name.columns.str.replace("␍", "", regex=False).str.strip()
```

## Columns with `[]`

```python
print(df["Name"].head(2).to_string())       # 1 col = Series
print(df[["Name", "Type1"]].head(2).to_string())  # list = table
```

## `.loc` — by NAME (includes end)

```python
print(df_name.loc["Pikachu"].to_string())  # whole row
```

```python
print(df_name.loc["Pikachu", "Weight"])  # one value
```

```python
print(df_name.loc[["Bulbasaur","Charmander"], ["Type1","Weight"]].to_string())
```

Slice includes BOTH ends:

```python
print(df.loc[0:2, ["Name","Weight"]].to_string())  # rows 0,1,2
```

## `.iloc` — by NUMBER (drops end)

```python
print(df.iloc[0].to_string())  # first row = Bulbasaur
print(df.iloc[0, 1])           # 'Bulbasaur'
```

```python
print(df.iloc[0:3, 1:4].to_string())  # rows 0,1,2 — end dropped
```

```python
print(df.iloc[-1].to_string())  # last = Mewtwo
```

Compare:

```python
print(df.loc[0:2, "Name"].to_string())   # 3 rows (includes 2)
print(df.iloc[0:2, 1].to_string())      # 2 rows (drops 2)
```

## One cell / shortcuts

```python
print(df.at[0, "Name"])  # by name, fast
print(df.iat[0, 1])      # by number, fastest
```

```python
print(df.query("Type1 == 'Fire' and Weight > 50")[["Name","Weight"]].to_string())
```

```python
print(df.filter(like="Type").head(2).to_string())  # Type1, Type2
```

```python
print(df.select_dtypes("number").head(2).to_string())  # No, Height, Weight
```

Real task — Charmander weight:

```python
print(df.set_index("Name").loc["Charmander", "Weight"])  # 8.5
```

## Reference

| Method | End? | Example |
|---|---|---|
| `df[[a,b]]` | — | `df[["Name","Weight"]]` |
| `.loc` | includes end | `df.loc[0:2]` → 0,1,2 |
| `.iloc` | drops end | `df.iloc[0:2]` → 0,1 |
| `.at/.iat` | single cell | `df.at[0,"Name"]` |
| `.query` | readable | `df.query("Weight>100")` |
| `.filter/.select_dtypes` | by name/type | `df.filter(like="Type")` |
