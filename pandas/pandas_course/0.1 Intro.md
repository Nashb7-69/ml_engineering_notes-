## ⚡ Quick Peek — the whole course in 30 seconds

| I want... | Code |
|---|---|
| Open file | `pd.read_csv(path)` |
| One column | `df["Name"]` |
| Pick cells | `df.loc["Pikachu", "Weight"]` / `df.iloc[0, 1]` |
| Keep rows that match | `df[df["Type1"] == "Fire"]` |
| Combine rules | `(a) & (b)` , `(a) \| (b)` , `~(a)` |
| Summarize | `df.groupby("Type1")["Weight"].mean()` |
| Fix headers | `df.columns.str.replace("␍","", regex=False).str.strip()` |
| Save | `df.to_csv("clean.csv", index=False)` |

## What is pandas?

Excel you control with code. Two objects only:

| Object | Think | Example |
|---|---|---|
| `Series` | one column | `df["Name"]` → 150 names |
| `DataFrame` | full sheet | `df` → 150 rows × 7 cols |

## Your file

150 Pokémon, 7 columns. Path: `/home/ravox/machine_learning/code/pokemon.csv`

```python
print(df.shape)  # (150, 7) = 150 rows, 7 cols
```

Columns:

```python
print(df.columns.tolist())
# ['No', 'Name', 'Type1', 'Type2', 'Height', 'Weight', 'Legendary␍']
```

That `␍` is real dirt. We clean it in [[3.2 Data Cleaning]] with one line — no loop needed.

3 real rows to picture it:

| No | Name | Type1 | Type2 | Weight |
|---|---|---|---|---|
| 1 | Bulbasaur | Grass | Poison | 6.9 |
| 4 | Charmander | Fire | NaN | 8.5 |
| 150 | Mewtwo | Psychic | NaN | 122.0 |

`NaN` = empty. Charmander has no Type2. Normal.
