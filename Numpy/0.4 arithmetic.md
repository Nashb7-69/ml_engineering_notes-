# math in arrays 
to do math in arrays we need numpy and using it bult in methods and modules just like in python for more refer to [[01.3_numbers#6. The `math` Module — Essential Functions]]
## scalar arithmetic 

```python
import numpy as np 

array= np.array([1,2,3])
print(array+2)
print(array-2)
print(array*2)
print(array/2)
print(array**2)
```


## Vectorized math functions 
``` python
import numpy as np 

array= np.array([1,2,3])

print(np.sqrt(array))
print(np.round(array))
print(np.floor(array))
print(np.ceil(array))
print(np.pi)
```

## Element-wise arithmetic
```python 
import numpy as np 
array1= np.array([1,2,3])
array2= np.array([4,5,6])
print(array1 + array2)
print(array1 - array2)
print(array1 * array2)
print(array1 / array2)
print(array1 ** array2)
```

## comparison operators

``` python
import numpy as np 

scores=np.array([91,55,100,72,82,64])

print(scores==100)                  #[False False  True False False False]
print(scores<60)                    #[False  True False False False False]
 
 #conditional assignment
scores[scores<=60]=0
print(scores)                       #[ 91   0 100  72  82  64]

```
